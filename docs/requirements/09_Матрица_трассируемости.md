# 09. Матрицы трассируемости (Traceability Matrices)

Составлено по методу K. Wiegers (гл. «Управление трассировкой требований»). Все ячейки основаны на фактических ссылках между файлами репозитория: исходные бизнес-постановки — изначально `*.doc` в корне (бинарные .doc-файлы удалены из репозитория) и их текстовые извлечения в `.extract/txt/`; требования — файлы `03`–`08`. Домыслы не добавлялись: если связь в источниках отсутствует, это отмечено прочерком или явным указанием.

Обозначения статусов: **Готово** — требование полностью сформулировано в БП; **Частично** — есть пробелы/двусмысленности (отражены в файле `07`); **Конфликт** — источники противоречат друг другу (C-n в файле `07`).

## 9.4. Выявленный пробел трассировки (факт аудита, не домысел)

При сверке каталога источников (68 файлов) с содержимым файла `03_Функциональные_требования.md` установлено: три бизнес-постановки об интеграциях описаны в контекстной диаграмме (файл `01`) и в правилах интеграций (файл `04`, §4.11), но **не имеют собственного идентификатора FR** в файле `03`:

1. `БП - Интеграция с СПУ` — компоненты: Проект, Система, Подсистема, Организация, Сотрудник организации, Госконтракт; цель: обмен данными с системой проектного управления (АСУР).
2. `БП - Интеграция с Тех. порталом` — компоненты: Система, Подсистема; функции: авт. заполнение реестров «Системы»/«Подсистемы», функция запроса в Тех. портал, журнал взаимодействия, проверка ответа; цель: исключить двойной ввод по ГК, показать РП распределение денег по годам/этапам и фактические выплаты; требование тиражируемости механизмов на другие сервисы ДИТ.Интеллект.
3. `БП — Интеграция ДИТ.Калькулятор с ДИТ.Мета` — данные метаданных БД (сервисы, FQN, ERD) для шаблонов ОИО; сопоставление систем по «ID техпортала».

Для полноты обратной трассировки им в этой матрице присвоены резервные идентификаторы **FR-INT-01 / FR-INT-02 / FR-INT-03**. Содержательно они уже отражены в файлах 01, 04 (§4.11) и 06 (§6.2); при ревизии файла 03 рекомендуется перенести их туда как отдельный подраздел «3.10. Интеграционные требования» без изменения формулировок.
