# 08. Глоссарий (Glossary / Data Dictionary)

Сводный глоссарий построен по всем разделам «1. Термины, определения, сокращения и обозначения» 57 документов. При расхождении определений варианты перечислены; систематические конфликты разобраны в файле 07 (§7.2).

## 8.1. Основные предметные термины

| Термин / сокращение | Определение (по источникам) |
|---|---|
| **ДИТ** | Департамент информационных технологий (в ряде документов: «…в том числе подведомственные юридические лица») |
| **ДИТ.Калькулятор / Сервис** | Сервис системы ДИТ.Интеллект для расчётов стоимости работ; встречается как «Сервис "ДИТ.Калькулятор"», «ДИТ.Калькулятор», «ДИТ.Интеллект Калькулятор 2.0» |
| **РСЗ** | Расчёт стоимости заявки |
| **ФОИ** | Функция обработки информации (в части источников — «Функции обработки информации») |
| **ФТ** | Варианты: «Функциональное требование», «Функциональные требования», «Функциональные точки» — конфликт C-6 |
| **БП** | Бизнес-постановка (документ требований); в модуле Конструктора РСЗ — также сущность реестра со статусами «В работе/На согласовании/Согласовано/На доработке» |
| **US** | User Story, пользовательская история (задача в МосТрек/Jira/M3) |
| **НМЦК** | Начальная (максимальная) цена контракта (варианты: «Начальная максимальная стоимость контракта», «Начальная максимальная цена контракта») |
| **ГК / Госконтракт** | Государственный контракт |
| **Этап ГК** | Этап государственного контракта (сущность НСИ с собственной статусной моделью) |
| **Закупка** | Сущность НСИ «Реестр закупок»; связана с ГК через поле «Номер ГК» |
| **СЗ / Служебное задание** | Задание на работы внутренними силами ДИТ (вне подрядных ГК) |
| **Внутренняя работа** | Работа, выполняемая сотрудниками ДИТ в рамках Этапа СЗ |
| **НСИ** | Нормативно-справочная информация (в источниках также с опечаткой «Нормативно-справочника информация») |
| **ИС / Система** | Информационная система; сущность реестра «Системы» |
| **Подсистема** | Составная часть Системы; носитель коэффициентов методики 3-Р и количества ФТ |
| **Проект (не ИС)** | Новая сущность НСИ, отличная от информационной системы |
| **Работа / Заявка** | Единица учёта работ подрядчика в рамках Этапа ГК (раздел эволюционировал из «Заявок») |
| **Итерация** | Цикл формирования/согласования ФОИ внутри расчёта; имеет признак «актуальная итерация» |
| **Методика 3-Р** | Методика расчёта стоимости (создание/развитие, рефакторинг); коэффициенты трудоёмкости МТ1–МТ8 |
| **Старая методика расчета** | Признак ФОИ/ГК (галка «Не учитывать изменения Методики 3-Р от 01.11.2023») |
| **Low-code / уровень языка разработки** | Значения поля подсистемы: «сверхвысокий (Low-code)» / «высокий/низкий (не Low-code)» |
| **чел.-мес.** | Человек-месяц, единица трудозатрат (округление в ПОЗ — до 2 знаков) |

## 8.2. Документы и артефакты

| Термин | Определение |
|---|---|
| **ОД** | Отчётная документация: ЧТЗ, ПЗ, ПМИ, ПОЗ, ОИО |
| **ЧТЗ** | Техническое задание (частное техническое задание); код децимального номера «ПТ» |
| **ПЗ** | Протокол заседания; код «П2» |
| **ПМИ** | Программа и методика испытаний; код «ПМ» |
| **ПОЗ** | Протокол обработки заявки |
| **ОИО** | Документ описание информационного объекта (структуры БД из ДИТ.Мета) |
| **ПФ / ЭФ** | Печатная форма / экранная форма |
| **ТЗ** | Техническое задание |
| **Децимальный номер (шифр документа без ЛУ)** | Составный идентификатор из 8 полей (см. 04 §4.6) |
| **СП** | Список рассылки (входит в архив выгрузки «ПЗ + СП + БП») |

## 8.3. Роли

| Термин | Определение по источникам |
|---|---|
| **Администратор** | Роль с полными правами в системе (редактирование, статусы, интеграции, справочники, стоимость) |
| **Администратор НСИ** | Роль управления записями НСИ и статусными моделями (СЗ, Типы работ, Дорожная карта) |
| **РП / РП ДИТ / Руководитель проекта (ДИТ)** | Согласование ГК и расчётов, календарные планы, ресурсное планирование, периоды работ |
| **Аналитик (Подрядчика)** | Формирование и редактирование ФОИ/БП/расчётов |
| **Аналитик (ДИТ) / Аналитик качества (ДИТ)** | Проверка и согласование ФОИ, замечания; ответственный за ФОИ фиксированной стоимости |
| **Пользователь** | Собирательное: «пользователь, обладающий одной из ролей: Аналитик Подрядчика, Аналитик Качества, Аналитик ДИТ, РП ДИТ, Администратор» (набор перечислений различается между документами) |
| **ФЗ** | Функциональный заказчик |
| **Заказчик / Пользователи системы** | Реквизиты карточки ГК/Системы, попадают в титульные листы ОД |
| **Ответственный аналитик / Ответственный подрядчик** | Назначаемые лица для перечня ФОИ фиксированной стоимости ГК (один аналитик на весь перечень) |

## 8.5. Статусы (сводник значений, встречающихся в источниках)

- Закупка: В работе, Завершено, Архив, Корзина (+ упомянуто «Отменено» без описания).
- ГК: Черновик, Согласование РП, В работе, Исполнено, Архив, Корзина.
- Этап ГК: Черновик, В работе, Оплачен(о), Архив, Корзина.
- Работа/Заявка: В работе, Оплачен, Архив, Корзина.
- СЗ: В работе, Завершено, Архив, Корзина. Этап СЗ: те же. Внутренняя работа: Черновик, В работе, Завершено, Архив, Корзина.
- ФОИ (расчёт/НМЦК): Черновик, В работе, На согласование, Согласовано, Не согласовано (+ исторические варианты «Согласован/Не согласован», приведены к единому виду; отдельная модель фиксированной стоимости включает «Новый», «На проверке», «На доработке», «Отклонено»).
- БП (Конструктор): В работе, На согласовании, Согласовано, На доработке.
- РСЗ: В работе, На согласовании у аналитика, На согласовании у РП (Согласовано РП), Согласовано, Доработка.
- Синхронизация НСИ: Успешно, Ошибка связи.
