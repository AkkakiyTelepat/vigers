# 4. Цель и концепция решения

4.1. Цели и обоснование необходимости развития

Цель - повысить удобство использования сервиса. Исключить лишние шаги пользователя по ручному заполнению каждой ФОИ.

4.2. Описание проблем и решения

На текущий момент пользователю приходится вручную вносить каждую ФОИ в сервис, что является не удобным при большом количестве ФОИ. Для решения проблемы предлагается реализовать парсер Excel файлов, позволяющий пользователю подгружать файл с ФОИ в систему.

# 8. Функции системы

8.1. Развитие ЭФ "Итерация" в части добавления возможности загрузки файла

Необходимо добавить на ЭФ "Итерация" кнопку добавления файла РСЗ (рисунок 2). При нажатии пользователем на кнопку должно открываться окно с возможностью добавления Excel файла РСЗ (рисунок 3).

8.2. Создания алгоритма парсинга Excel файлов с ФОИ

Пользователь должен иметь возможность добавления Excel файла РСЗ по предоставленному шаблону:

Шаблон для заполнения РСЗ.xlsx

ФОИ из Excel файла должны парситься системой и попадать на ЭФ "Итерация" так же, как если бы они были заполнены вручную.

Детальнее алгоритм должен быть описан в рамках системной постановки.
