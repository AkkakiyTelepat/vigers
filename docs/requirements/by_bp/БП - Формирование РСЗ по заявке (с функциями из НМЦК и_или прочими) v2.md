# 4. Цель и концепция решения

4.1. Цели и обоснование необходимости развития

Необходимо реализовать расчёт с типом РСЗ и ПФ ПОЗ, а также ЧТЗ, ПЗ и ПМИ с ФОИ, наименование и значимость ( Ф1-Ф8) которых идентичны указанным в НМЦК, без каких-либо принципиальных отличий.

Предполагалось, что при создании РСЗ в Калькуляторе пользователь сможет добавить ФОИ из НМЦК только в виде сопоставления со справочными значениями.

Концепция изменилась. Принято решение не вынуждать пользователя сопоставлять названия ФОИ в НМЦК со справочными значениями.

4.2. Описание проблем и решения

При текущей реализации пользователь вносит ФОИ в расчет выбирая наименование из справочника, в котором каждому наименованию ФОИ соответствует определенное значение значи мости (Ф1-Ф8) .

При этом в реальных расчетах НМЦК, публикуемых в составе закупки, названия функций и их значимость могут отличаться на справочных значений. Поскольку расчет НМЦК, публикуемый в составе закупки, проходит длинный цикл согласования, включая проверку ГБУ "Аналитический центр" и Межведомственной рабочей группы, сотрудники ДИТ юридические не вправе его пересматривать после заключения ГК на указанных условиях.

Для решения проблемы предлагается переработать блок НМЦК и переносить ФОИ из реестра "НМЦК по Заявке" в том виде, в котором они указаны в НМЦК путём добавления ФОИ из НМЦК в РСЗ.

# 7. Пользовательский сценарий (путь)

Порядок расчета РСЗ :

1. Авторизоваться в сервисе Калькулятор под ролью Аналитик подрядчика
2. Зайти в модуль "Расчет по методике 3-Р"
3. Зайти в раздел "Работы" (бывший раздел "Заявки")
4. Дважды кликнуть ЛКМ на искомой заявке, перейти на ЭФ "Работы" (бывшая ЭФ "Заявка")
5. Перейти в расчет дважды кликнув ЛКМ на строке "РСЗ"
6. Перейти в ЭФ последней активной итерации (та итерация, над которой ведутся работы - находится в "статусе" " Присутствуют ФОИ, ожидающие согласования ")
7. На ЭФ "Итерация № __" нажать на кнопку "Добавить ФОИ"
8. В открытой модальной форме "Добавление новой ФОИ" заполнить все необходимые поля
9. Нажать на кнопку "Сохранить"
10. После добавления всех ФОИ в РСЗ при необходимости нажать на кнопку "Добавить ФОИ НМЦК"
11. В открытой модальной форме "Добавление ФОИ НМЦК" выбрать из списка необходимую ФОИ, нажать сохранить.

# 8. Функции системы

8.1. Развитие ЭФ "Итерация"

Необходимо переработать ЭФ "Итерация" по следующим требованиям:

- Кнопку "+ Добавить" переименовать на "+ Добавить ФОИ"
- Добавить кнопку "+ Добавить ФОИ из НМЦК" при нажатии на которую должно открываться модальное окно " Добавление ФОИ из НМЦ К - выбор из справочника " (рис. 4)
- Столбцы "Наименование", "Уточняющая часть" должны быть объединены в столбец "Наименование и уточняющая часть" , информация в котором заполняется по принципу : для ФОИ созданной в модальном окне "Добавление новой ФОИ": "Наименование (из ЭФ Добавление новой ФОИ) "&" "&" Уточняющая часть "(из ЭФ Добавление новой ФОИ) (значения двух полей должны отображаться через разделитель в виде символа пробел ); для ФОИ созданной в модальном окне " Добавление новой функции НМЦК": "Наименование функции в НМЦК/ТЗ" (из ЭФ Добавление новой ФОИ из НМЦК) (без обработки)

При этом логика заведения ФОИ (прописывание наименования и уточняющей части в отдельных полях) и наследования полей в ЧТЗ не меняется.

- Столбец "Тип ФОИ НЦМК" должен быть убран
- Столбец "Стоимость" должен отображаться только для роли Администратор
- Столбец " НМЦК" должен быть переработан в части добавления чек-бокс а, чек-бокс автоматически проставляется активным (да), если ФОИ добавлена по кнопке "+ Добавить ФОИ из НМЦК", проставляется неактивным (нет), если ФОИ добавлена по кнопке "+ Добавить ФОИ"

Логика остальных столбцов остается без изменений (для ФОИ из НМЦК, указываются те же значения, что указаны в НСИ при заведении ФОИ).

8.2 Развитие экранной формы "добавление новой ФОИ" в части удаления поля ФОИ НМЦК

На экранной форме, вызываемой при нажатии кнопки "+ Добавить ФОИ" (ранее вызывалась при нажатии кнопки  "+ Добавить") необходимо удалить поле ФОИ НМЦК (рис. 5)

8.3 Создание модального окна "ФОИ из НМЦК - выбор из справочника"

Необходимо создать новое модальное окно (рис.4), которое должна открываться при нажатии на кнопку "+ Добавить ФОИ из НМЦК" в ЭФ "Итерация" (рис. 2).

Логика работы модального должна быть аналогична текущей логике работы поля ФОИ НМЦК в ЭФ "Добавление новой ФОИ" (рис. 3) . После выбора ФОИ из доступных и нажатия кнопки "Выбрать" , выбранные ФОИ должны отобразиться в ЭФ "Итерация" (рис. 2).

Отличия нового модального окна от старого выбора из справочника (рис. 3):

- Необходимо переименовать столбец "ФОИ НМЦК" в "ФОИ из НМЦК"
- В справочнике должны отображаться только ФОИ из НМЦК, указанные во вкладке "НМЦК по Заявке " для конкретного ГК , который указан в ЭФ "Работа" (бывшая Заявка) и не имеют статус "Согласован" в расчёте с типом РСЗ (в любых заявках/итерациях).

Путь: Расчет по методике 3-Р – НСИ – Реестр Государственные контракты – Вкладка НМЦК – Вкладка "НМЦК по Заявке"

- Должна быть реализована возможность выбора сразу нескольких значений из предложенного в модальном окне списка (при невозможности реализации - выбор одного значения)

8.4 Создания функции расчёта значений для ФОИ из НМЦК

Пользователь должен иметь возможность добавления ФОИ из НМЦК (ФОИ  указанные в разделе: НСИ → Редактор ГК → НМЦК → НМЦК по Заявке ). ФОИ должны быть доступны для выбора в модальном окне "ФОИ из НМЦК - выбор из справочника" (пункт 8.3).

Необходимо создать ограничение при котором ФОИ из НМЦК может быть добавлена только в один РСЗ в одном ГК . В случае если ФОИ была добавлена в одну из предыдущих заявок/работ в рамках выбранного ГК и имеет статус "согласовано" или "на согласование" она не должна отображаться пользователю в модальном окне " ФОИ из НМЦК - выбор из справочник а" будущих работ/заявок. .

ФОИ, добавленные по кнопке "+ Добавить ФОИ из НМЦК" в ЭФ "Итерация №" с типом "не задан" переносятся в ПФ ОД:

- ПФ РСЗ, ПОЗ в виде поля "Наименования и уточняющая часть" ФОИ (см. Рисунок 2), при этом строки с типом ФОИ и количеством ФТ не заполняются (остаются пустыми)
- ПФ ЧТЗ, ПЗ, ПМИ в виде поля "Наименования и уточняющая часть"  и "Описание" ФОИ .

Важно! добавленные ФОИ по кнопке "+ Добавить ФОИ из НМЦК" в ЭФ "Итерация №" с типом "не задан" не должны влиять на расчет стоимости.

8.5 Развитие ЭФ добавления и редактирования ФОИ НМЦК в Редакторе ГК в части добавления чек-бокса "Признак low-code"

На экранной форме добавления ФОИ НМЦК (рис.6) необходимо добавить чек-бокс " Признак low-code " (рис.7) по аналогии с признаком рефакторинга. При добавлении ФОИ НМЦК в заявку значение признака low-code для соответствующей ФОИ должно копироваться. На ЭФ добавления ФОИ  НМЦК в Редакторе ГК так же необходимо удалить поле "Комментарий".

Аналогично, чек-бокс  " Признак low-code " необходимо добавить для ЭФ редактирования ФОИ НМЦК в Редакторе ГК (рис. 8). На ЭФ редактирования ФОИ НМЦК в Редакторе ГК так же необходимо удалить поле "Комментарий".

8.6 Развитие вкладки "НМЦК по заявке" в части замены столбца "Комментарий" на столбец "Краткое описание"

На вкладке "НМЦК по заявке" (рис. 9), в реестре ФОИ столбец "Комментарий" необходимо заменить на столбец "Краткое описание" (рис. 10). Значение в столбце должно автоматически заполнятся значением, указанным пользователем в поле "Краткое описание" в ЭФ добавления или редактирования ФОИ НМЦК (рис. 7, рис. 8).

8.7 Развитие ЭФ редактирования ФОИ из НМЦК в РСЗ в части добавления редактируемого поля "Краткое описание"

На ЭФ редактирования ФОИ из НМЦК в РСЗ (рис. 11) необходимо добавить поле "Краткое описание" (рис. 12). Значение поля должно автоматически заполнятся значением, указанным в поле "Краткое описание" в ЭФ добавления или редактирования ФОИ из НМЦК (рис. 7, рис. 8). Поле должно быть доступно для редактирования.
