### A.4 Цель и концепция решения

4.1. Цели и обоснование необходимости развития

В рамках расширения пользования сервисом в будущем предполагается предоставить доступ к внесению коэффициентов трудоемкости руководителям проектов, для этого необходимо реализовать интуитивно понятный интерфейс

4.2. Описание проблем и решения

На данный момент просмотр коэффициентов трудоемкости для подсистем реализован неудобно. Пользователю, незнакомому с сервисом, не понятно где найти и внести коэффициенты трудоемкости.

Решение:

1. Вывод коэффициентов МТ1-МТ8 на ЭФ "Карточка подсистемы"
2. Автозаполнение номера ГК при добавлении коэффициентов для расчета по Методике 3-Р для подсистемы

### A.10 Функции системы (п.8, дословно)

8.1 Развитие ЭФ "Коэффициенты для расчета по методике 3-Р" из реестра ГК в части автоматического предзаполнения поля "Государственный контракт"

В случае если пользователь попадает на ЭФ "Коэффициенты для расчета по методике 3-Р" (рисунок 2) из реестра ГК (путь: Расчет по методике 3-р => НСИ => Реестр ГК => Карточка ГК => Подсистемы => Коэффициенты для расчета по методике 3-Р) поле "Государственный контракт" должно быть автоматически предзаполнено номером ГК, в карточке которого пользователь находится (не актуально для карточки ГК по старой методике).

8.2 Развитие ЭФ "Карточка подсистемы" из реестра подсистем в части переработки отображения коэффициентов

ЭФ "Карточка подсистемы" (путь: Расчет по методике 3-р => НСИ => Реестр подсистем =>Карточка подсистемы) должна быть переработана:

1. Карточка должна по умолчанию отображаться в полноэкранном режиме (рис. 4).
2. Поля "Уровень языка разработки" и "Коэффициент преобразования ФТ в РР" должны быть объединены в функциональный блок "Коэффициенты для старой версии Методики 3-Р" (рис. 4). Функциональный блок должно быть возможно свернуть/развернуть нажав на соответствующий символ рядом с наименованием блока (рис.4).
3. Функциональный блок "Коэффициенты для расчета по Методике 3-Р" должен быть переделан в части отображения заведенных коэффициентов для каждого существующего ГК (значения и наименования для всех существующих ГК должны автоматически подтягиваться) (рис. 4). Редактирование полей функционального блока должно осуществляться внутри карточки коэффициентов, которая открывается при нажатии на строку соответствующего ГК (логика работы не меняется).  Логика работы кнопок "Обновить", "Добавить", "Добавить на основе", "Редактировать" так же не меняется. Список полей обновленного функционального блока: Наименование ГК Номер ГК Дата заключения ГК Уровень языка разработки Коэффициент преобразования ФТ в БП Коэффициент переписывания программного кода МТ1 МТ2 МТ3 МТ4 МТ5 МТ6 МТ7 МТ8

# 4. Цель и концепция решения

4.1. Цели и обоснование необходимости развития

В рамках расширения пользования сервисом в будущем предполагается предоставить доступ к внесению коэффициентов трудоемкости руководителям проектов, для этого необходимо реализовать интуитивно понятный интерфейс

4.2. Описание проблем и решения

На данный момент просмотр коэффициентов трудоемкости для подсистем реализован неудобно. Пользователю, незнакомому с сервисом, не понятно где найти и внести коэффициенты трудоемкости.

Решение:

1. Вывод коэффициентов МТ1-МТ8 на ЭФ "Карточка подсистемы"
2. Автозаполнение номера ГК при добавлении коэффициентов для расчета по Методике 3-Р для подсистемы

В случае если пользователь попадает на ЭФ "Коэффициенты для расчета по методике 3-Р" (рисунок 2) из реестра ГК (путь: Расчет по методике 3-р => НСИ => Реестр ГК => Карточка ГК => Подсистемы => Коэффициенты для расчета по методике 3-Р) поле "Государственный контракт" должно быть автоматически предзаполнено номером ГК, в карточке которого пользователь находится (не актуально для карточки ГК по старой методике).

8.2 Развитие ЭФ "Карточка подсистемы" из реестра подсистем в части переработки отображения коэффициентов

ЭФ "Карточка подсистемы" (путь: Расчет по методике 3-р => НСИ => Реестр подсистем =>Карточка подсистемы) должна быть переработана:

1. Карточка должна по умолчанию отображаться в полноэкранном режиме (рис. 4).
2. Поля "Уровень языка разработки" и "Коэффициент преобразования ФТ в РР" должны быть объединены в функциональный блок "Коэффициенты для старой версии Методики 3-Р" (рис. 4). Функциональный блок должно быть возможно свернуть/развернуть нажав на соответствующий символ рядом с наименованием блока (рис.4).
3. Функциональный блок "Коэффициенты для расчета по Методике 3-Р" должен быть переделан в части отображения заведенных коэффициентов для каждого существующего ГК (значения и наименования для всех существующих ГК должны автоматически подтягиваться) (рис. 4). Редактирование полей функционального блока должно осуществляться внутри карточки коэффициентов, которая открывается при нажатии на строку соответствующего ГК (логика работы не меняется).  Логика работы кнопок "Обновить", "Добавить", "Добавить на основе", "Редактировать" так же не меняется.
