## Слой А. Структурированная карточка

### A.1 Термины и сокращения этой постановки

| Термин, сокращение | Определение |
|---|---|
| US (ФТ) | User Story (функциональное требование) |
| ПОЗ | Протокол обработки заявки |
| ДИТ | Департамент информационных технологий |
| Чел.-мес. | Человеко-месяцы |

### A.2 Подсистемы

ДИТ.Интеллект Калькулятор 2.0

### A.3 Компоненты (объекты доработки)

Работы, необходимы для реализации функционального требования, затрагивают:

- Серверный метод [ServerMethodGetPOZReportDataService]
- Шаблон печатной формы [Протокол обработки заявки (развитие)] (application_processing_protocol)
- Шаблон печатной формы [Протокол обработки заявки (рефакторинг)] (application_processing_protocol_ref)
- Шаблон печатной формы [Протокол обработки заявки (развитие+рефакторинг)] (application_processing_protocol_ref_dev)
- Шаблон печатной формы [Протокол обработки заявки (старая методика)] (application_processing_protocol_old)

### A.4 Цель и концепция решения

4.1. Цели и обоснование необходимости развития

Целью выполнения работ, необходимых для реализации функционального требования, является добавление в шаблон ПОЗ тега, содержащего трудозатраты, требующиеся на реализацию функций одного функционального требования (US) в рамках подсистемы , и округление до двух знаков после запятой значения количества чел.-мес. для каждой подсистемы и для каждой US .

4.2. Описание проблем и решения

Реализация работ, описанных в данной постановке, позволяет решить следующие проблемы:

- отсутствие сведений по количеству чел.-мес. в функциональных требованиях заявки и соответствующих им тегов в ПОЗ. Указывается только сумма для подсистемы с тегом {sum}, необходима декомпозиция и округление значений до двух знаков после запятой.

В открывшемся редакторе нажать на значок сохранения в области файла (см. рис. 5, выделено под №1), а затем после скачивания файла нажать на значок удаления в корзину (см. рис. 5, выделено под №2):

В 616 строке кода серверного метода ServerMethodGetPOZReportDataService (см. рис. 7) добавить в метод .Round , что округление идет до двух знаков после запятой:

Sum(x => x.FuncPointsCalc.CalculatedCost) / contractRate, 2)

В 628 строке кода создать переменную userStoryJObj["issue_personMonths"] с расчетной формулой:

userStoryJObj["issue_personMonths"] = isNewMethodic
                    ? this.Round(subsystemPair
                        .Value
                        .SelectMany(x => x.Value)
                        .Where(x => x.FuncPointsCalc.State.Code == Constants.ApprovedStateCode)
                        .Sum(x => x.FuncPointsCalc.CalculatedCost) / contractRate, 2)
                    : laborCostSubsystemsDict[userStoryPair.Key.Id];
