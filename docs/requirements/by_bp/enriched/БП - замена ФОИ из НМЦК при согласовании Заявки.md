### 1. Сценарий замены ФОИ из НМЦК в расчете Заявки

Предусловие: Пользователь авторизован в системе под ролью Руководитель проекта (РП) или Администратор и находится на экранной форме "Заявка", вкладка "Расчеты" → "РСЗ" → вкладка "ФОИ итерации".

1. Пользователь выбирает необходимую запись ФОИ из списка и нажимает кнопку "Редактировать".
2. Система выводит карточку "Изменение ФОИ из НМЦК" с предзаполненным полем "ФОИ НМЦК" (только чтение).
3. Пользователь включает чек-бокс "Заменить ФОИ".
4. Система делает поля "ФОИ" и "Уточняющая часть наименования ФОИ" доступными для редактирования.
5. Пользователь нажимает на значок выбора значения из справочника в поле "ФОИ".
6. Система выводит модальное окно "Выбор из справочника" со списком ФОИ, отфильтрованным по типу исходной (заменяемой) функции.
7. Пользователь выбирает новую ФОИ, заполняет поле "Уточняющая часть наименования ФОИ" и поле "Краткое описание", нажимает кнопку "Применить"/"Сохранить".
8. Система сохраняет изменения и обновляет данные в Редакторе ГК (вкладка "НМЦК" → подвкладка "НМЦК по Заявке", таблица "Использование в расчетах по заявкам").

Исключения и ошибки:

- Если чек-бокс "Заменить ФОИ" выключен, поля "ФОИ" и "Уточняющая часть наименования ФОИ" остаются заблокированными для редактирования, доступно только поле "Краткое описание".
- Если обязательные поля не заполнены или заполнены некорректно, система блокирует сохранение и выводит соответствующее информационное сообщение.

### 1. Доработать карточку "Изменение ФОИ из НМЦК" (вкладка "ФОИ итерации", ЭФ "Заявка")

Добавить чек-бокс "Заменить ФОИ" и сделать поля "ФОИ" и "Уточняющая часть наименования ФОИ" условно-редактируемыми.

Атрибутивный состав карточки "Изменение ФОИ из НМЦК"

| ФОИ | Да (при замене) | Активно только при включенном чек-боксе "Заменить ФОИ". Заполняется выбором значения из справочника, отфильтрованного по типу исходной ФОИ. |
| Уточняющая часть наименования ФОИ | Да (при замене) | Активно только при включенном чек-боксе "Заменить ФОИ". Заполняется вручную, текст. |

### 2. Сценарий замены задачи (ФТ) с ФОИ из НМЦК на вкладке "Задачи заявки"

Предусловие: Пользователь авторизован в системе под ролью Руководитель проекта (РП) и находится на экранной форме "Заявка", вкладка "Задачи заявки".

1. Пользователь выбирает строку с задачей, которую необходимо заменить, и нажимает кнопку "Заменить".
2. Система проверяет наличие ФОИ (вкладки "ФОИ итерации", "Согласованные ФОИ") и бизнес-постановок, связанных с данной задачей.
3. Если связанные данные отсутствуют, система выводит модальное окно "Массовое добавление записей" со справочником "Реестр функциональных требований", в котором первыми отображаются задачи без признака "Задача из НМЦК".
4. Пользователь выбирает новую задачу (ФТ) и нажимает кнопку "Готово".
5. Система добавляет новую задачу во вкладку "Задачи заявки", группирует её под исходной (замененной) задачей и отображает данные исходной задачи серым шрифтом, визуально показывая, что задача устарела.

Исключения и ошибки:

- Если у задачи есть связанные ФОИ и/или бизнес-постановки, система блокирует замену и выводит сообщение: "Замена задачи невозможна: в расчёт стоимости заявки внесены функции обработки информации и/или бизнес-постановки, связанные с данной задачей. Удалите функции обработки информации и/или бизнес-постановки."
- При удалении исходной задачи система автоматически удаляет связанную с ней новую задачу; если у новой задачи есть связанные ФОИ и/или бизнес-постановки, удаление блокируется с сообщением: "Удаление задачи невозможно: сначала удалите ФОИ и/или бизнес-постановки, связанные с новой задачей".
- При удалении новой задачи исходная задача перестаёт считаться заменённой и возвращается к обычному (активному) отображению.

### 3. Сценарий выгрузки реестра замен ФОИ по ГК

Предусловие: Пользователь находится в Редакторе ГК, вкладка "НМЦК" → подвкладка "НМЦК по Заявке".

1. Пользователь нажимает кнопку "Реестр замен ФОИ".
2. Система формирует Excel-файл со списком всех замен ФОИ, произведённых в рамках данного ГК (по всем Заявкам), сгруппированных по подсистеме и номеру задачи (ФТ).
3. Файл автоматически скачивается пользователю.

Исключения и ошибки:

- Если замен ФОИ в рамках ГК не производилось, выгружается файл, содержащий только заголовки столбцов, без строк с данными о заменах.

### 3. Добавить кнопку "Заменить" (вкладка "Задачи заявки", ЭФ "Заявка")

Кнопка располагается рядом с кнопками "Добавить" и "Удалить", становится активной при выборе строки с задачей. По нажатию открывается справочник "Реестр функциональных требований" (аналогично кнопке "Добавить"), если у выбранной задачи отсутствуют связанные ФОИ и бизнес-постановки.

### A.4 Цель и концепция решения

## 4.1. Цели и обоснование необходимости развития

Целью является обеспечение возможности замены ФОИ и задач (ФТ) из НМЦК в процессе согласования Заявки с сохранением прослеживаемости изменений в Редакторе ГК и печатных формах. Реализация затрагивает экранную форму "Заявка" (вкладка "Расчеты" → "РСЗ" → вкладка "ФОИ итерации", вкладка "Задачи заявки"), модальное окно "Массовое добавление записей", Редактор ГК (вкладка "НМЦК" → подвкладка "НМЦК по Заявке") и печатную форму Заявки. Компоненты предназначены для просмотра, редактирования, замены и выгрузки данных о ФОИ и задачах (ФТ), используемых при расчете стоимости заявки.


## 4.2. Описание проблем и решения

В настоящий момент замена ФОИ или задачи (ФТ), связанной с ФОИ из НМЦК, в рамках Заявки возможна только через удаление существующей записи и добавление новой, что приводит к потере истории и прослеживаемости изменений, а также не позволяет сформировать сводную информацию о произведенных заменах в рамках ГК. Печатная форма Заявки при этом не отражает факт и историю замены.

Реализация постановки позволяет заменять ФОИ и задачи (ФТ) из НМЦК на аналогичные непосредственно в карточках расчета, сохраняя ссылку на исходное значение, блокируя замену/удаление при наличии связанных расчетных данных, а также формировать выгружаемый реестр всех замен ФОИ по ГК и отражать факт замены в печатной форме Заявки.

### 4. Сценарий формирования печатной формы Заявки при наличии замены задачи

Предусловие: На вкладке "Задачи заявки" произведена замена хотя бы одной задачи.

1. Пользователь нажимает кнопку "Скачать Заявку".
2. Система формирует печатную форму Заявки по целевому шаблону: в столбце "Наименование задачи" отображается актуальное наименование задачи и указание на замену исходной задачи (с номером и наименованием), в столбце "Описание задачи/функциональные требования" отображается актуальное описание.

Исключения и ошибки:

- Если замен задач не производилось, печатная форма формируется по действующему шаблону без изменений.

### 4. Добавить кнопку "Реестр замен ФОИ" (Редактор ГК → вкладка "НМЦК" → подвкладка "НМЦК по Заявке")

При нажатии на кнопку автоматически формируется и скачивается Excel-файл (.xlsx), содержащий список всех замен ФОИ, произведённых в рамках данного ГК (по всем Заявкам).

Атрибутивный состав Excel-файла "Реестр замен ФОИ"

| Столбец | Описание |
|---|---|
| Порядковый номер | Указывается порядковый номер замены |
| Заменяемая ФОИ | Наименование исходной (старой) ФОИ – поле "Наименование ФОИ в НМЦК / ТЗ" (Редактор ГК → вкладка "НМЦК" → подвкладка "НМЦК по Заявке" → карточка "Изменение ФОИ НМЦК") |
| Заменённая ФОИ | Наименование новой ФОИ – поле "ФОИ" + поле "Уточняющая часть наименования ФОИ" (вкладка "ФОИ итерации" → карточка "Изменение ФОИ из НМЦК") |
| Номер Заявки | Номер Заявки, в которой произведена замена (в формате гиперссылки) |
| Старое краткое описание | Значение поля "Краткое описание" до замены (Редактор ГК → вкладка "НМЦК" → подвкладка "НМЦК по Заявке" → карточка "Изменение ФОИ НМЦК") |
| Новое краткое описание | Значение поля "Краткое описание" после замены (вкладка "ФОИ итерации" → карточка "Изменение ФОИ из НМЦК") |
| Дата замены | Дата и время сохранения изменений |
| Дата согласования РСЗ | Дата и время перехода РСЗ в статус "Согласовано" |

Группировка ФОИ в реестре соответствует группировке в Редакторе ГК (вкладка "НМЦК" → подвкладка "НМЦК по Заявке"): 1 уровень – по Подсистеме (в алфавитном порядке); 2 уровень – по Номеру задачи (ФТ) (в алфавитном порядке, по возрастанию).

При наличии замены во вкладке "Задачи заявки" печатная форма Заявки формируется в соответствии с целевым шаблоном: в столбце "Наименование задачи" отображается актуальное наименование задачи с указанием на замену исходной задачи (номер и наименование в ИСУП), в столбце "Описание задачи/функциональные требования" отображается актуальное описание задачи.

### A.8 Автоматизация бизнес-процессов / варианты использования (п.6)

В рамках данной Бизнес Постановки нет концептуальных изменений бизнес-процесса.

AS IS

Пользователь может только добавлять и удалять ФОИ и задачи (ФТ) из НМЦК в Заявке. Замена ФОИ или задачи фактически выполняется через удаление существующей записи и добавление новой, без сохранения истории и прослеживаемости изменений. Сводная информация о заменах ФОИ по ГК недоступна. Печатная форма Заявки не отражает факт замены.

TO BE

Пользователь может заменить ФОИ и задачу (ФТ) из НМЦК на аналогичную непосредственно в расчете Заявки. Система сохраняет ссылку на исходное значение, отображает исходные и новые данные, блокирует замену и удаление при наличии связанных расчетных данных (ФОИ, бизнес-постановок), формирует выгружаемый реестр всех замен ФОИ по ГК и отражает факт замены задачи в печатной форме Заявки.

## 7.2. [Описание алгоритмов]

Логика работы чек-бокса "Заменить ФОИ":

- Чек-бокс имеет два состояния: включен / выключен.
- При выключенном состоянии поля "ФОИ" и "Уточняющая часть наименования ФОИ" заблокированы для редактирования.
- При включенном состоянии поля "ФОИ" и "Уточняющая часть наименования ФОИ" становятся доступными для редактирования.

Правило фильтрации справочника ФОИ:

Доступный для выбора перечень ФОИ в поле "ФОИ" определяется типом исходной (заменяемой) функции (значение поля "Тип ФОИ" в Редакторе ГК) в соответствии с таблицей соответствия типов функциональных точек (Ф1–Ф8), закрепленной методикой 3-Р расчета стоимости.

Алгоритм замены задачи (ФТ):

- При нажатии кнопки "Заменить" система проверяет наличие ФОИ (вкладки "ФОИ итерации", "Согласованные ФОИ") и бизнес-постановок (по полю "Функциональное требование"), связанных с выбранной задачей.
- Если связанные данные найдены, замена блокируется с выводом информационного сообщения.
- Если связанные данные отсутствуют, открывается справочник "Реестр функциональных требований" для выбора новой задачи.
- После выбора новой задачи она добавляется во вкладку "Задачи заявки" и группируется под исходной (замененной) задачей; группировка по умолчанию раскрыта.

Алгоритм удаления задач при наличии замены:

- При удалении исходной задачи система автоматически удаляет связанную новую задачу; проверка связанных ФОИ и бизнес-постановок выполняется только для новой задачи.
- При удалении новой задачи исходная задача возвращается к обычному (активному) отображению; действуют стандартные правила проверки связанных данных.

Алгоритм формирования реестра замен ФОИ:

- По нажатию кнопки "Реестр замен ФОИ" система собирает данные обо всех произведенных заменах ФОИ в рамках текущего ГК по всем Заявкам.
- Сформированные данные группируются по Подсистеме (1 уровень) и Номеру задачи, ФТ (2 уровень) и выгружаются в Excel-файл по шаблону выгрузки.

Система проверяет наличие ФОИ и бизнес-постановок, связанных с задачей, перед выполнением операций замены и удаления, и блокирует операцию с выводом соответствующего информационного сообщения при обнаружении связанных данных.

# 4. Цель и концепция решения

## 4.1. Цели и обоснование необходимости развития

Целью является обеспечение возможности замены ФОИ и задач (ФТ) из НМЦК в процессе согласования Заявки с сохранением прослеживаемости изменений в Редакторе ГК и печатных формах. Реализация затрагивает экранную форму "Заявка" (вкладка "Расчеты" → "РСЗ" → вкладка "ФОИ итерации", вкладка "Задачи заявки"), модальное окно "Массовое добавление записей", Редактор ГК (вкладка "НМЦК" → подвкладка "НМЦК по Заявке") и печатную форму Заявки. Компоненты предназначены для просмотра, редактирования, замены и выгрузки данных о ФОИ и задачах (ФТ), используемых при расчете стоимости заявки.

## 4.2. Описание проблем и решения

В настоящий момент замена ФОИ или задачи (ФТ), связанной с ФОИ из НМЦК, в рамках Заявки возможна только через удаление существующей записи и добавление новой, что приводит к потере истории и прослеживаемости изменений, а также не позволяет сформировать сводную информацию о произведенных заменах в рамках ГК. Печатная форма Заявки при этом не отражает факт и историю замены.

Реализация постановки позволяет заменять ФОИ и задачи (ФТ) из НМЦК на аналогичные непосредственно в карточках расчета, сохраняя ссылку на исходное значение, блокируя замену/удаление при наличии связанных расчетных данных, а также формировать выгружаемый реестр всех замен ФОИ по ГК и отражать факт замены в печатной форме Заявки.

# 7. Пользовательский сценарий (путь)

### 1. Сценарий замены ФОИ из НМЦК в расчете Заявки

Предусловие: Пользователь авторизован в системе под ролью Руководитель проекта (РП) или Администратор и находится на экранной форме "Заявка", вкладка "Расчеты" → "РСЗ" → вкладка "ФОИ итерации".

1. Пользователь выбирает необходимую запись ФОИ из списка и нажимает кнопку "Редактировать".
2. Система выводит карточку "Изменение ФОИ из НМЦК" с предзаполненным полем "ФОИ НМЦК" (только чтение).
3. Пользователь включает чек-бокс "Заменить ФОИ".
4. Система делает поля "ФОИ" и "Уточняющая часть наименования ФОИ" доступными для редактирования.
5. Пользователь нажимает на значок выбора значения из справочника в поле "ФОИ".
6. Система выводит модальное окно "Выбор из справочника" со списком ФОИ, отфильтрованным по типу исходной (заменяемой) функции.
7. Пользователь выбирает новую ФОИ, заполняет поле "Уточняющая часть наименования ФОИ" и поле "Краткое описание", нажимает кнопку "Применить"/"Сохранить".
8. Система сохраняет изменения и обновляет данные в Редакторе ГК (вкладка "НМЦК" → подвкладка "НМЦК по Заявке", таблица "Использование в расчетах по заявкам").

Исключения и ошибки:

- Если чек-бокс "Заменить ФОИ" выключен, поля "ФОИ" и "Уточняющая часть наименования ФОИ" остаются заблокированными для редактирования, доступно только поле "Краткое описание".
- Если обязательные поля не заполнены или заполнены некорректно, система блокирует сохранение и выводит соответствующее информационное сообщение.

### 2. Сценарий замены задачи (ФТ) с ФОИ из НМЦК на вкладке "Задачи заявки"

Предусловие: Пользователь авторизован в системе под ролью Руководитель проекта (РП) и находится на экранной форме "Заявка", вкладка "Задачи заявки".

1. Пользователь выбирает строку с задачей, которую необходимо заменить, и нажимает кнопку "Заменить".
2. Система проверяет наличие ФОИ (вкладки "ФОИ итерации", "Согласованные ФОИ") и бизнес-постановок, связанных с данной задачей.
3. Если связанные данные отсутствуют, система выводит модальное окно "Массовое добавление записей" со справочником "Реестр функциональных требований", в котором первыми отображаются задачи без признака "Задача из НМЦК".
4. Пользователь выбирает новую задачу (ФТ) и нажимает кнопку "Готово".
5. Система добавляет новую задачу во вкладку "Задачи заявки", группирует её под исходной (замененной) задачей и отображает данные исходной задачи серым шрифтом, визуально показывая, что задача устарела.

Исключения и ошибки:

- Если у задачи есть связанные ФОИ и/или бизнес-постановки, система блокирует замену и выводит сообщение: "Замена задачи невозможна: в расчёт стоимости заявки внесены функции обработки информации и/или бизнес-постановки, связанные с данной задачей. Удалите функции обработки информации и/или бизнес-постановки."
- При удалении исходной задачи система автоматически удаляет связанную с ней новую задачу; если у новой задачи есть связанные ФОИ и/или бизнес-постановки, удаление блокируется с сообщением: "Удаление задачи невозможно: сначала удалите ФОИ и/или бизнес-постановки, связанные с новой задачей".
- При удалении новой задачи исходная задача перестаёт считаться заменённой и возвращается к обычному (активному) отображению.

### 3. Сценарий выгрузки реестра замен ФОИ по ГК

Предусловие: Пользователь находится в Редакторе ГК, вкладка "НМЦК" → подвкладка "НМЦК по Заявке".

1. Пользователь нажимает кнопку "Реестр замен ФОИ".
2. Система формирует Excel-файл со списком всех замен ФОИ, произведённых в рамках данного ГК (по всем Заявкам), сгруппированных по подсистеме и номеру задачи (ФТ).
3. Файл автоматически скачивается пользователю.

Исключения и ошибки:

- Если замен ФОИ в рамках ГК не производилось, выгружается файл, содержащий только заголовки столбцов, без строк с данными о заменах.

### 4. Сценарий формирования печатной формы Заявки при наличии замены задачи

Предусловие: На вкладке "Задачи заявки" произведена замена хотя бы одной задачи.

1. Пользователь нажимает кнопку "Скачать Заявку".
2. Система формирует печатную форму Заявки по целевому шаблону: в столбце "Наименование задачи" отображается актуальное наименование задачи и указание на замену исходной задачи (с номером и наименованием), в столбце "Описание задачи/функциональные требования" отображается актуальное описание.

Исключения и ошибки:

- Если замен задач не производилось, печатная форма формируется по действующему шаблону без изменений.

## 7.1. [Пользовательские интерфейсы]

Описание изменений форм

### 1. Доработать карточку "Изменение ФОИ из НМЦК" (вкладка "ФОИ итерации", ЭФ "Заявка")

Добавить чек-бокс "Заменить ФОИ" и сделать поля "ФОИ" и "Уточняющая часть наименования ФОИ" условно-редактируемыми.

Атрибутивный состав карточки "Изменение ФОИ из НМЦК"

| Наименование поля | Обязательность заполнения | Примечание |
|---|---|---|
| ФОИ НМЦК | Нет (только чтение) | Поле неактивно, не редактируется. Предзаполнено наименованием исходной (заменяемой) функции. |
| ФОИ | Да (при замене) | Активно только при включенном чек-боксе "Заменить ФОИ". Заполняется выбором значения из справочника, отфильтрованного по типу исходной ФОИ. |
| Уточняющая часть наименования ФОИ | Да (при замене) | Активно только при включенном чек-боксе "Заменить ФОИ". Заполняется вручную, текст. |
| Краткое описание | Да | Всегда активно. Заполняется вручную, текст. |
| Чек-бокс "Заменить ФОИ" | Нет | Управляет режимом замены (включен/выключен). |

### 2. Добавить столбец "Задача из НМЦК" (ЭФ "Массовое добавление записей", вкладка "Задачи заявки")

| Наименование поля | Обязательность заполнения | Примечание |
|---|---|---|
| Задача из НМЦК | Нет | Нередактируемый чек-бокс. Состояние "Включен" – задача добавлена в ГК (Редактор ГК → "НМЦК" → "НМЦК по Заявке"); состояние "Выключен" – задача отсутствует в ГК. При добавлении задачи первыми в списке отображаются задачи с включенным чек-боксом, затем – с выключенным. При замене задачи первыми отображаются задачи с выключенным чек-боксом, затем – с включенным. |

### 3. Добавить кнопку "Заменить" (вкладка "Задачи заявки", ЭФ "Заявка")

Кнопка располагается рядом с кнопками "Добавить" и "Удалить", становится активной при выборе строки с задачей. По нажатию открывается справочник "Реестр функциональных требований" (аналогично кнопке "Добавить"), если у выбранной задачи отсутствуют связанные ФОИ и бизнес-постановки.

### 4. Добавить кнопку "Реестр замен ФОИ" (Редактор ГК → вкладка "НМЦК" → подвкладка "НМЦК по Заявке")

При нажатии на кнопку автоматически формируется и скачивается Excel-файл (.xlsx), содержащий список всех замен ФОИ, произведённых в рамках данного ГК (по всем Заявкам).

Атрибутивный состав Excel-файла "Реестр замен ФОИ"

| Столбец | Описание |
|---|---|
| Порядковый номер | Указывается порядковый номер замены |
| Заменяемая ФОИ | Наименование исходной (старой) ФОИ – поле "Наименование ФОИ в НМЦК / ТЗ" (Редактор ГК → вкладка "НМЦК" → подвкладка "НМЦК по Заявке" → карточка "Изменение ФОИ НМЦК") |
| Заменённая ФОИ | Наименование новой ФОИ – поле "ФОИ" + поле "Уточняющая часть наименования ФОИ" (вкладка "ФОИ итерации" → карточка "Изменение ФОИ из НМЦК") |
| Номер Заявки | Номер Заявки, в которой произведена замена (в формате гиперссылки) |
| Старое краткое описание | Значение поля "Краткое описание" до замены (Редактор ГК → вкладка "НМЦК" → подвкладка "НМЦК по Заявке" → карточка "Изменение ФОИ НМЦК") |
| Новое краткое описание | Значение поля "Краткое описание" после замены (вкладка "ФОИ итерации" → карточка "Изменение ФОИ из НМЦК") |
| Дата замены | Дата и время сохранения изменений |
| Дата согласования РСЗ | Дата и время перехода РСЗ в статус "Согласовано" |

Группировка ФОИ в реестре соответствует группировке в Редакторе ГК (вкладка "НМЦК" → подвкладка "НМЦК по Заявке"): 1 уровень – по Подсистеме (в алфавитном порядке); 2 уровень – по Номеру задачи (ФТ) (в алфавитном порядке, по возрастанию).

### 5. Доработать печатную форму Заявки (кнопка "Скачать Заявку")

При наличии замены во вкладке "Задачи заявки" печатная форма Заявки формируется в соответствии с целевым шаблоном: в столбце "Наименование задачи" отображается актуальное наименование задачи с указанием на замену исходной задачи (номер и наименование в ИСУП), в столбце "Описание задачи/функциональные требования" отображается актуальное описание задачи.

## 7.2. [Описание алгоритмов]

Логика работы чек-бокса "Заменить ФОИ":

- Чек-бокс имеет два состояния: включен / выключен.
- При выключенном состоянии поля "ФОИ" и "Уточняющая часть наименования ФОИ" заблокированы для редактирования.
- При включенном состоянии поля "ФОИ" и "Уточняющая часть наименования ФОИ" становятся доступными для редактирования.

Правило фильтрации справочника ФОИ:

Доступный для выбора перечень ФОИ в поле "ФОИ" определяется типом исходной (заменяемой) функции (значение поля "Тип ФОИ" в Редакторе ГК) в соответствии с таблицей соответствия типов функциональных точек (Ф1–Ф8), закрепленной методикой 3-Р расчета стоимости.

Алгоритм замены задачи (ФТ):

- При нажатии кнопки "Заменить" система проверяет наличие ФОИ (вкладки "ФОИ итерации", "Согласованные ФОИ") и бизнес-постановок (по полю "Функциональное требование"), связанных с выбранной задачей.
- Если связанные данные найдены, замена блокируется с выводом информационного сообщения.
- Если связанные данные отсутствуют, открывается справочник "Реестр функциональных требований" для выбора новой задачи.
- После выбора новой задачи она добавляется во вкладку "Задачи заявки" и группируется под исходной (замененной) задачей; группировка по умолчанию раскрыта.

Алгоритм удаления задач при наличии замены:

- При удалении исходной задачи система автоматически удаляет связанную новую задачу; проверка связанных ФОИ и бизнес-постановок выполняется только для новой задачи.
- При удалении новой задачи исходная задача возвращается к обычному (активному) отображению; действуют стандартные правила проверки связанных данных.

Алгоритм формирования реестра замен ФОИ:

- По нажатию кнопки "Реестр замен ФОИ" система собирает данные обо всех произведенных заменах ФОИ в рамках текущего ГК по всем Заявкам.
- Сформированные данные группируются по Подсистеме (1 уровень) и Номеру задачи, ФТ (2 уровень) и выгружаются в Excel-файл по шаблону выгрузки.

# 8. Функции системы

## 8.1. Реализация функции замены ФОИ из НМЦК в расчете Заявки с сохранением прослеживаемости

При редактировании ФОИ на вкладке "ФОИ итерации" система предоставляет пользователю чек-бокс "Заменить ФОИ". При включении чек-бокса становятся доступны для редактирования поля "ФОИ" и "Уточняющая часть наименования ФОИ"; выбор новой ФОИ ограничен справочником, отфильтрованным по типу исходной функции. Поле "ФОИ НМЦК" сохраняет наименование исходной функции для истории. После сохранения изменения отображаются в Редакторе ГК (вкладка "НМЦК" → подвкладка "НМЦК по Заявке").

## 8.2. Реализация функции замены задачи (ФТ) с ФОИ из НМЦК в Заявке

На вкладке "Задачи заявки" реализуется кнопка "Заменить", позволяющая выбрать новую задачу (ФТ) взамен исходной при отсутствии связанных с исходной задачей ФОИ и бизнес-постановок. Новая задача группируется под исходной, исходная задача визуально помечается как устаревшая.

## 8.3. Реализация блокировки удаления и замены задачи при наличии связанных данных

Система проверяет наличие ФОИ и бизнес-постановок, связанных с задачей, перед выполнением операций замены и удаления, и блокирует операцию с выводом соответствующего информационного сообщения при обнаружении связанных данных.

## 8.4. Реализация функции формирования и выгрузки реестра замен ФОИ по ГК

В Редакторе ГК реализуется кнопка "Реестр замен ФОИ", формирующая Excel-файл со сводной информацией обо всех заменах ФОИ, произведенных в рамках ГК по всем Заявкам, с группировкой по подсистеме и номеру задачи (ФТ).

## 8.5. Доработка печатной формы Заявки с учетом произведенных замен задач

Печатная форма Заявки дорабатывается в соответствии с целевым шаблоном и отражает информацию о произведенной замене задачи (ФТ).

## 8.6. Переименование поля "Код задачи"

Отдельная доработка сохраняется как справочная информация: в рамках связанной постановки поле "Код задачи" переименовывается в "Номер задачи" во всех местах системы, где оно используется.

# 9. [Требования к информации (данным)]

Состав информации, выгружаемой в файле "Реестр замен ФОИ" (.xlsx), приведен в п. 7.1 настоящей Бизнес Постановки (таблица "Атрибутивный состав Excel-файла «Реестр замен ФОИ»").

Нет
