### Бизнес-правила для полей

#### Обязательные поля (при переходе из Черновика в Активна)

- Название работы
- Тип работы (из справочника)
- Дата выполнения (не может быть в будущем, если статус «Завершена»)
- Трудозатраты (Размер команды: Кол-во сотрудников, раб.дней, мес., человеко-мес., ставка каждого сотрудника)
- Статус
- Тип основания (из справочника)
- Номер основания (текст, не более 9 символов)

#### Правила для основания

- Тип основания – выпадающий список, значения: Проект Организация
- Номер основания – ссылка на соответствующий документ в системе (если есть). Допустимо вручную указать номер.

#### Трудозатраты

- Могут быть изменены только до статуса «Завершена».
- После завершения изменение трудозатрат возможно только с комментарием (аудит).

#### Дата выполнения

- При создании – текущая дата.
- Может быть изменена в прошлое или будущее, но если статус «Завершена», дата не может быть позже сегодняшней.

### A.4 Цель и концепция решения

4.1. Цели и обоснование необходимости развития

Подготовить раздел «Внутренние работы», который позволяет фиксировать, хранить и просматривать все работы над системой, выполняемые сотрудниками ДИТ вне рамок Государственных Контрактов. Необходимость введения такого раздела обуславливается необходимостью:

- учёта внутренней трудовой нагрузки;
- исключения задвоения работ с подрядчиками;
- прозрачности изменений системы;
- формирования отчётности по внутренним доработкам.

### Бизнес-правила для полей

#### Обязательные поля (при переходе из Черновика в Активна)

- Название работы

- Статус
- Тип основания (из справочника)
- Номер основания (текст, не более 9 символов)

#### Правила для основания

- Тип основания – выпадающий список, значения: Проект Организация
- Номер основания – ссылка на соответствующий документ в системе (если есть). Допустимо вручную указать номер.

#### Трудозатраты

- Могут быть изменены только до статуса «Завершена».
- После завершения изменение трудозатрат возможно только с комментарием (аудит).

#### Дата выполнения

- При создании – текущая дата.
- Может быть изменена в прошлое или будущее, но если статус «Завершена», дата не может быть позже сегодняшней.
