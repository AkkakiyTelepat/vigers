## 7.1. Описание алгоритмов

1. Расчет Готовности отчетных документов (ОД) в этапе

Необходимо рассчитывать готовность отчетных документов в рамках Этапа ГК.

Готовность ОД в Этапе ГК = округлить до целого значения ((сумма по количеству ОД в этапе в статусе "Подписан" /сумма по количеству ОД в этапе, статус которых != "Отклонен") * 100%)

Если Плановая дата окончания Этапа < Текущей даты И Готовность ОД в Этапе ГК != 100%, то система подсвечивает поле "Красным" цветом

Иначе система подсвечивает поле "Зеленым" цветом

2.  Расчет Дней до окончания работы/заявки

Необходимо рассчитывать количество оставшихся дней до окончания работы

Кол-во оставшихся дней = (Плановая дата окончания Этапа - Текущая дата)

Если значение отрицательное, то система подсвечивает поле "Красным" цветом

Если значение положительное ИЛИ равно 0, то система подсвечивает поле "Зеленым" цветом

3. Готовность отчетных документов в работе/заявке

Необходимо рассчитывать готовность отчетных документов в рамках Работы/Заявки.

Готовность ОД в Работе/Заявке = округлить до целого значения ((количество ОД в работе (закупке) в статусе "Подписан" /количество ОД в работе (закупке), статус которых != "Отклонен") * 100%)

Если Плановая дата окончания Этапа < Текущей даты И Готовность ОД в Работе/Заявке != 100%, то система подсвечивает поле "Красным" цветом

Иначе система подсвечивает поле "Зеленым" цветом

### A.10 Функции системы (п.8, дословно)

8.1.1 Развитие функции отображения информации пользователем через интерфейс системы на ЭФ "Редактор ГК" путем добавления вкладки "Календарный план ГК"

Необходимо создать вкладку "Календарный план ГК" на ЭФ "Редактор ГК"

Путь до ЭФ: Главная страница/Расчет по методике 3-Р/НСИ/Редактор ГК/вкладка "Календарный план ГК"

Макет вкладки "Календарный план ГК" на ЭФ "Редактор ГК" представлен на рисунке 1

Цель доработки: Доработать карточку ГК в части создания вкладки "Календарный план ГК" для отображения сводной аналитики по бюджету и заполнению отчетных документов по ГК в разрезе Этапов ГК и Работ/Заявок

Необходимо создать вкладку "Календарный план ГК". На вкладке будет расположен реестр "Календарный план ГК" состоящий из 3 уровней вложенности: 1. Этап ГК, 2. Работа/Заявка, 3. Отчетные документы.

Реестр должен автоматически формироваться наполняясь информацией из сущностей Этап ГК, Работа/Заявка, Отчетный документ (Проект документа) в момент заведения карточки Госконтракта и обновляться данными в момент создания/редактирования данных в карточках Этапа ГК, Работы/Заявки, Отчетного документа.

В реестре необходимо настроить сортировку по следующему принципу:

1. Сортировка для реестра 1 уровня: Первая сортировка по "Статус": Сначала статус В работе, потом статус Черновик, далее статус Подписано (все что подписано улетает вниз реестра) Вторая сортировка по "Номер Этапа": От меньшего к большему
2. Сортировка для реестра 2 уровня: Первая сортировка по "Статус работы/Заявки": Сначала статус В работе, потом статус Черновик, далее статус Оплачено (все что оплачено улетает вниз реестра) Вторая сортировка по "Номер Работы/Заявки": От меньшего к большему
3. Сортировка для реестра 3 уровня: Первая сортировка по "Статус документа": Сначала статус Все статусы кроме Черновик и Подписано, потом статус Черновик, далее статус Оплачено (все что оплачено улетает вниз реестра)

Статус Архив не учтен в сортировке, т.к. переход в этот статус осуществляется только после перевода всех документов в предфинальный статус (Оплачено, Подписано). При переводе в статус Архив сортировка осуществляется только по Номеру Этапа и Номеру работы/заявки

Перечень атрибутов для формирования реестра приведен в таблице 2 настоящей бизнес-постановки

В реестре будет доступна функция "Обновления".

Просмотр вкладки доступен следующим ролям: Администратор, Администратор НСИ, Руководитель проекта

8.2.1 Развитие функции отображения информации пользователю в таком же виде, как она хранится во внутренних файлах ИС для ЭФ "Этап ГК"

Необходимо добавить на ЭФ "Этап ГК" поле "Расчетная стоимость выполнения работ по этапу" с автоматическим расчетом значения

Значение в поле расчетное и считается по следующей формуле:

"Расчетная стоимость выполнения работ по этапу" = Сумма по полю "Сумма согласованная" по всем Заявкам и Работам, которые входят в Этап ГК

Необходимо добавить на ЭФ "Этап ГК" поле "Фактическая стоимость работ по этапу" с возможностью ручного редактирования значения

## 7.1. Описание алгоритмов

1. Расчет Готовности отчетных документов (ОД) в этапе

Необходимо рассчитывать готовность отчетных документов в рамках Этапа ГК.

Готовность ОД в Этапе ГК = округлить до целого значения ((сумма по количеству ОД в этапе в статусе "Подписан" /сумма по количеству ОД в этапе, статус которых != "Отклонен") * 100%)

Если Плановая дата окончания Этапа < Текущей даты И Готовность ОД в Этапе ГК != 100%, то система подсвечивает поле "Красным" цветом

Иначе система подсвечивает поле "Зеленым" цветом

2.  Расчет Дней до окончания работы/заявки

Необходимо рассчитывать количество оставшихся дней до окончания работы

Кол-во оставшихся дней = (Плановая дата окончания Этапа - Текущая дата)

Если значение отрицательное, то система подсвечивает поле "Красным" цветом

Если значение положительное ИЛИ равно 0, то система подсвечивает поле "Зеленым" цветом

3. Готовность отчетных документов в работе/заявке

Необходимо рассчитывать готовность отчетных документов в рамках Работы/Заявки.

Готовность ОД в Работе/Заявке = округлить до целого значения ((количество ОД в работе (закупке) в статусе "Подписан" /количество ОД в работе (закупке), статус которых != "Отклонен") * 100%)

Если Плановая дата окончания Этапа < Текущей даты И Готовность ОД в Работе/Заявке != 100%, то система подсвечивает поле "Красным" цветом

Иначе система подсвечивает поле "Зеленым" цветом

8.1.1 Развитие функции отображения информации пользователем через интерфейс системы на ЭФ "Редактор ГК" путем добавления вкладки "Календарный план ГК"

Необходимо создать вкладку "Календарный план ГК" на ЭФ "Редактор ГК"

Путь до ЭФ: Главная страница/Расчет по методике 3-Р/НСИ/Редактор ГК/вкладка "Календарный план ГК"

Макет вкладки "Календарный план ГК" на ЭФ "Редактор ГК" представлен на рисунке 1

Цель доработки: Доработать карточку ГК в части создания вкладки "Календарный план ГК" для отображения сводной аналитики по бюджету и заполнению отчетных документов по ГК в разрезе Этапов ГК и Работ/Заявок

Необходимо создать вкладку "Календарный план ГК". На вкладке будет расположен реестр "Календарный план ГК" состоящий из 3 уровней вложенности: 1. Этап ГК, 2. Работа/Заявка, 3. Отчетные документы.

Реестр должен автоматически формироваться наполняясь информацией из сущностей Этап ГК, Работа/Заявка, Отчетный документ (Проект документа) в момент заведения карточки Госконтракта и обновляться данными в момент создания/редактирования данных в карточках Этапа ГК, Работы/Заявки, Отчетного документа.

В реестре необходимо настроить сортировку по следующему принципу:

1. Сортировка для реестра 1 уровня: Первая сортировка по "Статус": Сначала статус В работе, потом статус Черновик, далее статус Подписано (все что подписано улетает вниз реестра) Вторая сортировка по "Номер Этапа": От меньшего к большему
2. Сортировка для реестра 2 уровня: Первая сортировка по "Статус работы/Заявки": Сначала статус В работе, потом статус Черновик, далее статус Оплачено (все что оплачено улетает вниз реестра) Вторая сортировка по "Номер Работы/Заявки": От меньшего к большему
3. Сортировка для реестра 3 уровня: Первая сортировка по "Статус документа": Сначала статус Все статусы кроме Черновик и Подписано, потом статус Черновик, далее статус Оплачено (все что оплачено улетает вниз реестра)

Статус Архив не учтен в сортировке, т.к. переход в этот статус осуществляется только после перевода всех документов в предфинальный статус (Оплачено, Подписано). При переводе в статус Архив сортировка осуществляется только по Номеру Этапа и Номеру работы/заявки
