## 7.2. [Описание алгоритмов]

### A.10 Функции системы (п.8, дословно)

1.1 Создание справочника/реестра "Реестр Тип работ"

Для управления различными типами работ в Этапах ГК необходимо реализовать форму "Реестр Тип работ". На форме необходимо создать реестр.

Реестр на форме "Реестр Тип работ" должен содержать следующие поля:

| № | Название поля | Значение поля | Применение | Обязательность заполнения | Справочное значения | Справочник | Комментарий |
|---|---|---|---|---|---|---|---|
| 1 | Тип проекта | Классификатор Типа проекта из СПУ | Выбор из списка | Да | Нет | Нет |  |
| 2 | Вид работ | Классификатор Вида работ по Этапу ГК | Вручную | Да | Нет | Нет |  |
| 3 | Тип работ | Классификатор Типа работ в Работе/Заявке | Вручную | Да | Нет | Нет |  |
| 4 | Подтип работ | Классификатор Подтипа работ для определения комплекта отчетной документации в Работе/Заявке | Вручную | Да | Нет | Нет |  |
| 5 | Тип расходов | Классификатор Тип расходов для определения расчета бюджетных средств | Выбор из списка | Да | Нет | Нет |  |

На форме "Реестр Тип работ" должны быть отображены следующие элементы:

| № | Название | Значение кнопки | Действие системы при активации | Тип элемента | Состояние элемента | Особенности | Комментарий |
|---|---|---|---|---|---|---|---|
| 1 | Обновить | Необходима для обновления таблицы | Система обновляет значения в таблице | Кнопка | Всегда ативен |  |  |
| 1 | Добавить | Необходима для добавления новой записи в реестр | Система отображает форму "Добавление Тип работ" | Кнопка | Всегда активен |  |  |
| 2 | Редактировать | Необходима для редактирования записи в реестре | Система отображает форму "Тип работ" | Кнопка | Активен после активации чек/бокса "Выбрать Тип работ" |  |  |
| 3 | Удалить | Необходима для удаления записи(ей) в реестре | Система отображает модальное окно "Удаление" | Кнопка | Активен после активации чек/бокса(ов) "Выбрать Тип работ" |  |  |
| 4 | Выбрать Тип работ | Необходим для выбора срок(и) в реестре для последующего Удаления или Редактирования | Система выделяет документ и активирует кнопки "Редактировать" и "Удалить" | Чек/бокс | По умолчанию деактивирован(ы) | Если выбрано одно значение, то система активирует кнопки "Редактирование" и "Удалить" Если выбрано более одного чек/бокса, то система деактивирует кнопку "Редактирование" | Чек/бокс есть в каждой строке(записи) реестра |
| 5 | Подробнее | Необходима для редактирования записи в реестре | Система отображает форму "Тип работ" | Кликабельный текст | Всегда активен(ы) |  | Кликабельный текст есть в каждой строке(записи) реестра |

Примерный вид формы для отображения пользователю приведен на макете Макет 1.1 настоящего документа.

На форме "Удаление" отображаются следующие элементы:

| № | Название | Значение кнопки | Действие системы при активации | Тип элемента | Состояние элемента | Особенности | Комментарий |
|---|---|---|---|---|---|---|---|
| 1 | Да | Необходима для подтверждения удаления записей в реестре | Система удаляет записи из реестра и отображает справочник "Реестр Тип работ" без удаленных записей | Кнопка | Всегда активен |  |  |
| 2 | Нет | Необходима для отмены удаления записей в реестре | Система отображает форму "Реестр Тип работ" | Кнопка | Всегда активен |  |  |
