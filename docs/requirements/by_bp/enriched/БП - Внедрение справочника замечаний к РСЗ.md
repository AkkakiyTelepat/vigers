### A.9 Пользовательский сценарий и алгоритмы (п.7)

1. Пользователь под ролью Аналитик ДИТ авторизовался в сервисе Калькулятор

3. Перейти в карточку необходимого расчета в статусе "Согласовано РП"
4. Перейти итерацию согласования
5. Выбрать ФОИ к которой необходимо оставить комментарий
6. Нажать на статус ФОИ и выбрать статус "Не согласован"
7. В открывшемся окне "Изменение статуса" нажать кнопку "Выбрать типовое значение"

### A.10 Функции системы (п.8, дословно)

8.1 Развитие ЭФ "Добавление замечания" (РСЗ) в части добавления кнопки "Выбрать типовое замечание"

Необходимо добавить кнопку «Выбрать типовое замечание» на ЭФ "Добавить замечание". Макет - рис. 2, рис. 4. Кнопка должна отображаться только при переводе в статус "Не согласовано"

При проверке РСЗ в карточке расчета на вкладке "ФОИ итерации" у аналитика ДИТ или аналитика качества есть возможность перевести ФОИ в статус «Не согласовано». При попытке смены статуса открывается модальное окно с полем для ввода текста замечания, кнопкой «Применить» и кнопкой «Отмена».

В существующее модальное окно необходимо добавить кнопку «Выбрать типовое замечание» . При нажатии на кнопку должно открываться модальное окно с возможностью выбора одного из типовых замечаний для проверяемой ФОИ.

Расположение : под полем ввода текста (слева от кнопки "Отменить") (рис. 2).

8.2 Создание модального окна выбора типового замечания

При нажатии на кнопку «Выбрать типовое замечание» открывается дополнительное модальное окно «Реестр типовых замечаний» (см. рисунок 3), содержащее список из 12 типовых замечаний в соответствии со справочником Справочник типовых замечаний.xlsx Окно должно содержать кнопки: кнопка «Отмена» закрывает окно выбора без внесения изменений, кнопка «Добавить замечание» вставляет текст выбранного замечания (столбец "Типовое замечание" в справочнике) в поле ввода исходного модального окна «Добавить замечание». П оле ввода остается полностью доступным для редактирования. Аналитик ДИТ или Аналитик качества может:

- Дополнить текст (например, указать номера ФОИ для объединения)
- Удалить или изменить любую часть подставленного текста
- Исправить формулировку

При массовом выборе нескольких ФОИ и смене их статуса на «Не согласовано» (рис. 4):

- Открывается стандартное модальное окно с полем ввода текста
- Кнопка «Выбрать типовое замечание» работает аналогично
- Текст замечания применяется ко всем выбранным ФОИ

Функционал сохранения не меняется:

- После нажатия кнопки «Сохранить» статус ФОИ изменяется на «Не согласовано»
- Текст замечания сохраняется в истории ФОИ

8.3 Создание справочника типовых замечаний

Необходимо создать справочник типовых замечаний к ФОИ. Состав атрибутов справочника:

- Тип ошибки
- Типовое замечание

На текущий момент справочник должен быть заполнен 12 записями в соответствии с файлом Справочник типовых замечаний.xlsx

Справочник должен располагаться в разделе НСИ и быть доступным для редактирования для роли "Администратор" или "Администратор НСИ".

При нажатии на кнопку «Выбрать типовое замечание» открывается дополнительное модальное окно «Реестр типовых замечаний» (см. рисунок 3), содержащее список из 12 типовых замечаний в соответствии со справочником Справочник типовых замечаний.xlsx Окно должно содержать кнопки: кнопка «Отмена» закрывает окно выбора без внесения изменений, кнопка «Добавить замечание» вставляет текст выбранного замечания (столбец "Типовое замечание" в справочнике) в поле ввода исходного модального окна «Добавить замечание». П оле ввода остается полностью доступным для редактирования. Аналитик ДИТ или Аналитик качества может:

- Дополнить текст (например, указать номера ФОИ для объединения)
- Удалить или изменить любую часть подставленного текста
- Исправить формулировку

При массовом выборе нескольких ФОИ и смене их статуса на «Не согласовано» (рис. 4):

- Открывается стандартное модальное окно с полем ввода текста
- Кнопка «Выбрать типовое замечание» работает аналогично
- Текст замечания применяется ко всем выбранным ФОИ

Функционал сохранения не меняется:

- После нажатия кнопки «Сохранить» статус ФОИ изменяется на «Не согласовано»
- Текст замечания сохраняется в истории ФОИ

8.3 Создание справочника типовых замечаний

Необходимо создать справочник типовых замечаний к ФОИ. Состав атрибутов справочника:

- Тип ошибки
- Типовое замечание

На текущий момент справочник должен быть заполнен 12 записями в соответствии с файлом Справочник типовых замечаний.xlsx

Справочник должен располагаться в разделе НСИ и быть доступным для редактирования для роли "Администратор" или "Администратор НСИ".
