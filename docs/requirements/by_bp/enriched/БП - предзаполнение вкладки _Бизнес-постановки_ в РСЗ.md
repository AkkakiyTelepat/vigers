### A.10 Функции системы (п.8, дословно)

8.1 Создание алгоритма предзаполнения вкладки "Бизнес-постановки"

В текущей реализации вкладка "Бизнес-постановки" не предзаполняется (Рисунок 1).

Путь: главная - Расчет по методике 3-Р - Работы - выбрать нужную двойным кликом ЛКМ - РСЗ - Итерация - вкладка Бизнес-постановка

Необходимо разработать алгоритм, который будет инициироваться при следующих условиях:

1. РП ДИТ или администратор сохранили (применили) изменения на вкладке "Задачи заявки". (Главная- Расчет по методике 3-Р - Заявки - открыть заявку - вкладка "Задачи заявки")
2. Система заполнила вкладку "Бизнес-постановки" записями БП с задачами из вкладки "Задачи заявки".

На вкладке БП должны автоматически создаваться записи с задачами US, которые добавлены на вкладке "Задачи заявки" (Рисунок 2). Примечание: Вкладка "Задачи заявки" реализуется в рамках БП - БП - Реализация вкладки "Задачи заявки"

Правило формирования записей:

Статичный текст: " Бизнес-постановка на реализацию " далее символ " «" , значение поля " Код задачи " из справочника ФТ, символ ":" , значение поля " Наименование задачи" из справочника ФТ и символ "»"

Итоговая формула: Бизнес-постановка на реализацию « Код задачи: Наименование задачи »

Пример записи: Бизнес-постановка на реализацию «PLATFKGH-1065: 1. [ДИТ.Архитектура] Создание инструмента проектирование системы»

Макет предзаполненной вкладки отражен на рисунке 3.

С помощью кнопки "Добавить" пользователь загружает дополнительные БП (логика не меняется). В справочнике функциональных требований, открываемом при заполнении поля "Функциональное требование" должен быть отражен список US с вкладки "Задачи заявки" (рис. 6).

Кнопка "Редактировать"  должна становиться активной после выбора предзаполненной записи БП. С помощью данной кнопки пользователь может загружать файл в существующую предзаполненную запись БП или заменять его.

8.2 Развитие всплывающих подсказок на вкладке "Бизнес-постановки"

Необходимо заменить текст подсказок на вкладке "Бизнес-постановки"

Путь: главная - Расчет по методике 3-Р - Работы - выбрать нужную двойным кликом ЛКМ - РСЗ - Итерация - вкладка Бизнес-постановка - иконка знака вопроса

Старый текст: В данном разделе находятся файлы с бизнес-постановками в рамках данной заявки . (рис. 4)

Новый текст:

"В данном разделе находятся файлы с бизнес-постановками в рамках формируемой заявки.

Для загрузки бизнес-постановки выберите нужную строку в таблице и нажмите кнопку "Редактировать".

Если к задаче требуется прикрепить несколько бизнес-постановок, используйте кнопку "Добавить" ." (рис. 5).

Необходимо добавить подсказку на ЭФ Выбора ФТ из справочника при ручном добавлении БП по кнопке "Добавить".

Путь: главная - Расчет по методике 3-Р - Работы - выбрать нужную двойным кликом ЛКМ - РСЗ - Итерация - вкладка Бизнес-постановка - Добавить - Функциональное требование

При наведении на иконку вопроса должна отобразиться подсказка с текстом: " Справочник функциональных требований Если задачи отсутствуют, обратитесь к руководителю проекта для заполнения задач User Story на вкладке "Задачи заявки" ". (рис. 7)

8.3 Развитие ЭФ редактирования БП в части автоматического заполнения поля "Функциональное требование"

При нажатии кнопки "Редактировать" на вкладке "Бизнес-постановки" должно открыться окно "Бизнес-постановка" с заполненным наименованием функционального требования (Рисунок 8). На ЭФ должно быть предзаполнено поле "Функциональное требование". Поле должно заполнятся тем ФТ, которое указано в наименовании БП, которую пользователь открыл для редактирования.

Пользователь не должен иметь возможность редактировать поле "Функциональное требование". При этом для БП, добавляемых вручную (через кнопку "Добавить"), поле "Функциональное требование" должно быть доступно для редактирования.

Путь: главная - Расчет по методике 3-Р - Работы - выбрать нужную двойным кликом ЛКМ - РСЗ - Итерация - вкладка Бизнес-постановка - Редактировать

На вкладке БП должны автоматически создаваться записи с задачами US, которые добавлены на вкладке "Задачи заявки" (Рисунок 2). Примечание: Вкладка "Задачи заявки" реализуется в рамках БП - БП - Реализация вкладки "Задачи заявки"

Правило формирования записей:

Статичный текст: " Бизнес-постановка на реализацию " далее символ " «" , значение поля " Код задачи " из справочника ФТ, символ ":" , значение поля " Наименование задачи" из справочника ФТ и символ "»"

Итоговая формула: Бизнес-постановка на реализацию « Код задачи: Наименование задачи »

Пример записи: Бизнес-постановка на реализацию «PLATFKGH-1065: 1. [ДИТ.Архитектура] Создание инструмента проектирование системы»

Макет предзаполненной вкладки отражен на рисунке 3.

С помощью кнопки "Добавить" пользователь загружает дополнительные БП (логика не меняется). В справочнике функциональных требований, открываемом при заполнении поля "Функциональное требование" должен быть отражен список US с вкладки "Задачи заявки" (рис. 6).

Кнопка "Редактировать"  должна становиться активной после выбора предзаполненной записи БП. С помощью данной кнопки пользователь может загружать файл в существующую предзаполненную запись БП или заменять его.

8.2 Развитие всплывающих подсказок на вкладке "Бизнес-постановки"

Необходимо заменить текст подсказок на вкладке "Бизнес-постановки"

Путь: главная - Расчет по методике 3-Р - Работы - выбрать нужную двойным кликом ЛКМ - РСЗ - Итерация - вкладка Бизнес-постановка - иконка знака вопроса

"В данном разделе находятся файлы с бизнес-постановками в рамках формируемой заявки.

Для загрузки бизнес-постановки выберите нужную строку в таблице и нажмите кнопку "Редактировать".

Необходимо добавить подсказку на ЭФ Выбора ФТ из справочника при ручном добавлении БП по кнопке "Добавить".

Путь: главная - Расчет по методике 3-Р - Работы - выбрать нужную двойным кликом ЛКМ - РСЗ - Итерация - вкладка Бизнес-постановка - Добавить - Функциональное требование

При наведении на иконку вопроса должна отобразиться подсказка с текстом: " Справочник функциональных требований Если задачи отсутствуют, обратитесь к руководителю проекта для заполнения задач User Story на вкладке "Задачи заявки" ". (рис. 7)

8.3 Развитие ЭФ редактирования БП в части автоматического заполнения поля "Функциональное требование"

При нажатии кнопки "Редактировать" на вкладке "Бизнес-постановки" должно открыться окно "Бизнес-постановка" с заполненным наименованием функционального требования (Рисунок 8). На ЭФ должно быть предзаполнено поле "Функциональное требование". Поле должно заполнятся тем ФТ, которое указано в наименовании БП, которую пользователь открыл для редактирования.

Пользователь не должен иметь возможность редактировать поле "Функциональное требование". При этом для БП, добавляемых вручную (через кнопку "Добавить"), поле "Функциональное требование" должно быть доступно для редактирования.
