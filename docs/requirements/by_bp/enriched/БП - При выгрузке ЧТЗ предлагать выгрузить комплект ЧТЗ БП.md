### A.4 Цель и концепция решения

4.1. Цели и обоснование необходимости развития

Цель - повысить удобство использования сервиса. Исключить лишние шаги по выгрузки постановок для пользователей.

4.2. Описание проблем и решения

На текущий момент пользователю приходится выгружать документы ЧТЗ, ПЗ и каждую постановку отдельно, чтобы потом приложить к документу. Отсутствует возможность выгрузки архива (ЧТЗ + все БП, ПЗ + все СП). Необходимо добавить такую возможность.

В шаблоне ТЗ существует требование по наличию в ЧТЗ прототипов пользовательских интерфейсов в редактируемом виде, для выполнения требования предлагается реализовать возможность приложения файлов с прототипами в ЭФ "Итерация"

### A.10 Функции системы (п.8, дословно)

8.1. Развитие ЭФ "Итоговое ЧТЗ по заявке"

На экранной форме ЧТЗ из вкладки "Итоговые документы" необходимо добавить кнопку "Скачать архив (ЧТЗ + Приложения)" согласно макету на рисунке 2. Также необходимо создать на экранной форме раздел "Приложение 2" с подразделом " Перечень прототипов, прилагаемых на машинном носителе ". Раздел состоять из полей:

- Наименование бизнес-постановки
- Наименование прототипа
- Наименование файла прототипа на машинном носителе информации с указанием формата файла

Раздел должен автоматически предзаполнятся прототипами приложенными в ЭФ "Итерации" во вкладке "Прототипы" (рис. 5) по аналогии с пред заполнением бизнес-постановок в приложении 1.

8.2. Развитие ЭФ "Итоговая ПЗ по заявке"

На экранной форме ПЗ из вкладки "Итоговые документы" необходимо добавить кнопку "Скачать архив (ПЗ + СП)" согласно макету на рисунке 4

8.3. Создание функции выгрузки архива документов ЧТЗ + Приложения

При нажатии на кнопку "Скачать архив (ЧТЗ + Приложения)" на устройство пользователя должен выгружаться zip архив (с наименованием "ЧТЗ с приложениями") , состоящий из документов: ЧТЗ, все БП, приложенные к нему (Перечень приложенных БП доступен в согласованном РСЗ во вкладке "Итерация" в разделе "Бизнес постановки"), все прототипы приложенные к нему (Перечень приложенных прототипов доступен в согласованном РСЗ во вкладке "Итерация" в разделе "Прототипы"). Наименование архива должно совпадать с наименованием, выгружаемого ЧТЗ (ЧТЗ_Наименование системы_Номер ГК_Номер Заявки).

Актуальный шаблон ЧТЗ - Шаблон_ЧТЗ_02.03.2026.docx

8.4. Создание функции выгрузки архива документов ПЗ + относящиеся к нему СП

При нажатии на кнопку "Скачать архив (ПЗ + СП)" на устройство пользователя должен выгружаться zip архив (с наименованием "ПЗ с приложениями") , состоящий из документов: ПЗ а так же все все СП, приложенные к нему (СП прикладываются к каждой БП на этапе формирования ПЗ), а также БП.  Наименование архива должно совпадать с наименованием, выгружаемого ПЗ (ПЗ_Наименование системы_Номер ГК_Номер Заявки).

8.5 Развитие ЭФ "Итерации" в части добавления возможности прикладывать файлы с прототипами

На экранной форме "Итерации" необходимо создать вкладку "Прототипы" (рис. 5). Функциональность вкладки должна быть аналогична вкладке "Бизнес-постановки".

Пользователь с ролью Аналитик подрядчика должен иметь возможность добавлять файлы прототипов при нажатии на кнопку "Добавить"

Пользователь с ролью Аналитик ДИТ должен иметь возможность прожимать чек-бокс "Прототип соответствует приложенному файлу" (аналогично постановкам)

Любой пользователь должен иметь возможность скачать приложенные файлы по нажатию на наименование файла (выгрузиться выбранный файл) либо на кнопку "Скачать файлы" (выгрузятся все файлы)

При наведении курсора мыши на иконку подсказки рядом с надписью "Прототипы" пользователю должна выводиться всплывающая подсказка с текстом: "В данном разделе находятся файлы с прототипами пользовательских интерфейсов в редактируемом формате (fig или аналогичные)"

8.6 Создание ЭФ добавление прототипа

Необходимо создать ЭФ добавления прототипа (рис. 6). Функциональность должна быть аналогична ЭФ добавления бизнес постановки и состоять из полей:

| Наименование поля | Принцип заполнения | Обязательность |
|---|---|---|
| Наименование бизнес-постановки | В поле "Наименование бизнес-постановки" пользователю должен быть доступен выбор из справочника тех БП, которые уже приложены на соответствующей вкладке | Да |
| Наименование прототипа | Текстовый ввод | Да |
| Файл прототипа | Поле для импорта файлов любого формата | Да |
| Описание | Текстовый ввод | Нет |

Для роли Аналитик ДИТ должен быть доступен чек-бокс " Прототип соответствует приложенному файлу" аналогично ЭФ добавления бизнес-постановок.

# 8. Функции системы

8.1. Развитие ЭФ "Итоговое ЧТЗ по заявке"

На экранной форме ЧТЗ из вкладки "Итоговые документы" необходимо добавить кнопку "Скачать архив (ЧТЗ + Приложения)" согласно макету на рисунке 2. Также необходимо создать на экранной форме раздел "Приложение 2" с подразделом " Перечень прототипов, прилагаемых на машинном носителе ". Раздел состоять из полей:

- Наименование бизнес-постановки
- Наименование прототипа
- Наименование файла прототипа на машинном носителе информации с указанием формата файла

Раздел должен автоматически предзаполнятся прототипами приложенными в ЭФ "Итерации" во вкладке "Прототипы" (рис. 5) по аналогии с пред заполнением бизнес-постановок в приложении 1.

8.2. Развитие ЭФ "Итоговая ПЗ по заявке"

На экранной форме ПЗ из вкладки "Итоговые документы" необходимо добавить кнопку "Скачать архив (ПЗ + СП)" согласно макету на рисунке 4

8.3. Создание функции выгрузки архива документов ЧТЗ + Приложения

При нажатии на кнопку "Скачать архив (ЧТЗ + Приложения)" на устройство пользователя должен выгружаться zip архив (с наименованием "ЧТЗ с приложениями") , состоящий из документов: ЧТЗ, все БП, приложенные к нему (Перечень приложенных БП доступен в согласованном РСЗ во вкладке "Итерация" в разделе "Бизнес постановки"), все прототипы приложенные к нему (Перечень приложенных прототипов доступен в согласованном РСЗ во вкладке "Итерация" в разделе "Прототипы"). Наименование архива должно совпадать с наименованием, выгружаемого ЧТЗ (ЧТЗ_Наименование системы_Номер ГК_Номер Заявки).

Актуальный шаблон ЧТЗ - Шаблон_ЧТЗ_02.03.2026.docx

8.4. Создание функции выгрузки архива документов ПЗ + относящиеся к нему СП

При нажатии на кнопку "Скачать архив (ПЗ + СП)" на устройство пользователя должен выгружаться zip архив (с наименованием "ПЗ с приложениями") , состоящий из документов: ПЗ а так же все все СП, приложенные к нему (СП прикладываются к каждой БП на этапе формирования ПЗ), а также БП.  Наименование архива должно совпадать с наименованием, выгружаемого ПЗ (ПЗ_Наименование системы_Номер ГК_Номер Заявки).

8.5 Развитие ЭФ "Итерации" в части добавления возможности прикладывать файлы с прототипами

На экранной форме "Итерации" необходимо создать вкладку "Прототипы" (рис. 5). Функциональность вкладки должна быть аналогична вкладке "Бизнес-постановки".

Пользователь с ролью Аналитик подрядчика должен иметь возможность добавлять файлы прототипов при нажатии на кнопку "Добавить"

Пользователь с ролью Аналитик ДИТ должен иметь возможность прожимать чек-бокс "Прототип соответствует приложенному файлу" (аналогично постановкам)

Любой пользователь должен иметь возможность скачать приложенные файлы по нажатию на наименование файла (выгрузиться выбранный файл) либо на кнопку "Скачать файлы" (выгрузятся все файлы)

При наведении курсора мыши на иконку подсказки рядом с надписью "Прототипы" пользователю должна выводиться всплывающая подсказка с текстом: "В данном разделе находятся файлы с прототипами пользовательских интерфейсов в редактируемом формате (fig или аналогичные)"

8.6 Создание ЭФ добавление прототипа

Необходимо создать ЭФ добавления прототипа (рис. 6). Функциональность должна быть аналогична ЭФ добавления бизнес постановки и состоять из полей:

| Наименование поля | Принцип заполнения | Обязательность |
|---|---|---|
| Наименование бизнес-постановки | В поле "Наименование бизнес-постановки" пользователю должен быть доступен выбор из справочника тех БП, которые уже приложены на соответствующей вкладке | Да |
| Наименование прототипа | Текстовый ввод | Да |
| Файл прототипа | Поле для импорта файлов любого формата | Да |
| Описание | Текстовый ввод | Нет |

Для роли Аналитик ДИТ должен быть доступен чек-бокс " Прототип соответствует приложенному файлу" аналогично ЭФ добавления бизнес-постановок.
