### A.9 Пользовательский сценарий и алгоритмы (п.7)

Сценарий 1. Просмотр ЭФ ПЗ.

Предусловие: Пользователь авторизован в системе и находится на главной странице ДИТ.Калькулятор

1. Пользователь выбирает пункт "Расчет по Методике 3-Р" в боковой панели стартовой страницы;

2. Открывается меню второго уровня

3. Пользователь выбирает "Работы"

4. Отображается ЭФ "Работы" с перечнем работ, сгруппированных по ГК

5. Пользователь двойным кликом ЛКМ открывает заявку/работу.

6. Отображается ЭФ " Заявка №"/ЭФ "Работа по ГК №"

7. Пользователь переходит на вкладку "Шаблоны документов"

8. Отображается ЭФ "Шаблоны документов"

9. Пользователь выбирает тип документа: ПЗ

10. Отображается соответствующая ЭФ Редактора ПЗ. Конец сценария.

Сценарий 2. Просмотр ПФ ПЗ.

Предусловие: Пользователь авторизован в системе и находится на главной странице ДИТ.Калькулятор

1. Пользователь выбирает пункт "Расчет по Методике 3-Р" в боковой панели стартовой страницы;

2. Открывается меню второго уровня

3. Пользователь выбирает "Работы"

4. Отображается ЭФ "Работы" с перечнем работ, сгруппированных по ГК

5. Пользователь двойным кликом ЛКМ открывает заявку/работу.

6. Отображается ЭФ " Заявка №"/ЭФ "Работа по ГК №"

7. Пользователь переходит на вкладку "Шаблоны документов"

8. Отображается ЭФ "Шаблоны документов"

9. Пользователь выбирает тип документа: ПЗ

10. Отображается соответствующая ЭФ Редактора ПЗ

11. Пользователь нажимает кнопку « Скачать ПЗ »

11.1. Также пользователь может нажать кнопку « Скачать архив (ПЗ + СП + БП) » / « Скачать архив (ПЗ + Приложения) ».

12. Система формирует и выгружает документ ПЗ (или архив с документом ПЗ).

13. Пользователь открывает скачанный файл. Конец сценария.

Сценарий 3. Заполнение подраздела Описание процесса деятельности раздела.

Предусловие: Пользователь авторизован в системе и находится на главной странице ДИТ.Калькулятор

1. Пользователь выбирает пункт "Расчет по Методике 3-Р" в боковой панели стартовой страницы;

2. Открывается меню второго уровня

3. Пользователь выбирает "Работы"

4. Отображается ЭФ "Работы" с перечнем работ, сгруппированных по ГК

5. Пользователь двойным кликом ЛКМ открывает заявку/работу.

6. Отображается ЭФ " Заявка №"/ЭФ "Работа по ГК №"

7. Пользователь переходит на вкладку "Шаблоны документов"

8. Отображается ЭФ "Шаблоны документов"

9. Пользователь выбирает тип документа: ПЗ

10. Отображается соответствующая ЭФ Редактора ПЗ

11. Пользователь переходит в подраздел Описание процесса деятельности раздела 2. Описание процесса деятельности.

12. В ПЗ отображается таблица со столбцом "Пользовательские требования (Сценарий)"

13. Пользователь нажимает кнопку "Копировать из ЧТЗ"

14. Отображаются скопированные US.

15. Пользователь двойным кликом ЛКМ нажимает на столбец "Пользовательские требования (Сценарий)"

16. Отображается модальное окно ввода с не редактируемым полем в виде номера и наименования US, полем ввода "Объект автоматизации/автоматизированный процесс (процесс)" и полем для ввода текста в столбец "Пользовательские требования (Сценарий)".

17.  Пользователь заполняет поля. Конец сценария.
