### 1. Развитие экранной формы «ФОИ итерации» (вкладка заявки)

#### 1.1 Создание функции отображения кнопки «Добавить пустую ФОИ»

Необходимо добавить кнопку «Добавить пустую ФОИ» на панель управления таблицей ФОИ на экранной форме «ФОИ итерации». Кнопка должна располагаться рядом с основной кнопкой «Добавить» и быть визуально отличимой (например, через иконку или подпись «быстро»). Кнопка активна всегда при наличии у пользователя прав на редактирование заявки. При нажатии на кнопку открывается модальное окно с двумя обязательными полями: «Подсистема» и «Функциональное требование» .

#### 1.2 Создание функции отображения модального окна с выбором Подсистемы и Функционального требования

На экранной форме «ФОИ итерации» необходимо реализовать модальное окно «Создание пустой ФОИ» , открывающееся по нажатию кнопки из п. 1.1. Модальное окно должно содержать следующие элементы:

| № | Название Поля | Применение | Тип Элемента | Обязательность |
|---|---|---|---|---|
| 1 | Подсистема | Выбор из справочника «Подсистемы» | Выпадающий список | Да |
| 2 | Функциональное требование | Выбор из справочника «Функциональные требования», отфильтрованного по выбранной Подсистеме | Выпадающий список | Да |

На форме должны быть отображены следующие элементы управления:

| № | Элемент | Назначение | Поведение | Тип | Условие активности |
|---|---|---|---|---|---|
| 1 | Сохранить | Подтверждение создания ФОИ | При нажатии система создаёт новую запись ФОИ со статусом «Черновик» и закрывает окно | Кнопка | Активна, если оба поля заполнены |
| 2 | Отмена | Закрытие окна без сохранения | Окно закрывается, запись не создаётся | Кнопка / иконка | Всегда активна |

#### 1.3 Создание функции отображения таблицы ФОИ с ограничением in-line редактирования

В реестре ФОИ на вкладке «Итерации» должны отображаться все атрибуты ФОИ, включая:

- Статус
- Наименование
- Уточняющая часть наименования
- Краткое описание
- Тип ФОИ
- Признак low-code
- НМЦК

Однако in-line редактирование должно быть разрешено только для двух полей :

| Поле | Тип | Редактируемость |
|---|---|---|
| Уточняющая часть наименования | Текстовое поле (однострочное) | Да (только в статусе «Черновик») |
| Краткое описание | Текстовое поле (многострочное) | Да (только в статусе «Черновик») |

Все остальные поля (включая Наименование ) - только для просмотра , даже если ФОИ находится в статусе «Черновик».

#### 1.4 Создание функции блокировки редактирования по статусу

Система должна проверять статус ФОИ перед отображением ячеек в режиме редактирования:

- Если статус = 'Черновик' → разрешить in-line редактирование только для двух полей.
- Если статус ≠ 'Черновик' (например, «В работа», «На согласовании», «Согласовано») → все поля недоступны для редактирования in-line .
- При попытке клика по не редактируемой ячейке - отображать всплывающую подсказку: «Редактирование доступно только для ФОИ в статусе "Черновик"» .

#### 1.5 Создание функции валидации при переводе в статус «В работа»

При выполнении операции перевода ФОИ из статуса «Черновик» в статус «В работа» система должна проверить:

- Поле «Уточняющая часть наименования» ≠ пустое
- Поле «Краткое описание» ≠ пустое

Условие успешного выполнения: оба поля заполнены. Результат: статус меняется на «В работа», все поля блокируются для редактирования in-line.

Условие ошибки: хотя бы одно поле пустое. Валидационное сообщение: «Для перевода в статус "В работа" необходимо заполнить: Уточняющую часть и Краткое описание» .

- Тип ФОИ

#### 1.4 Создание функции блокировки редактирования по статусу

Система должна проверять статус ФОИ перед отображением ячеек в режиме редактирования:

- Если статус = 'Черновик' → разрешить in-line редактирование только для двух полей.
- Если статус ≠ 'Черновик' (например, «В работа», «На согласовании», «Согласовано») → все поля недоступны для редактирования in-line .
- При попытке клика по не редактируемой ячейке - отображать всплывающую подсказку: «Редактирование доступно только для ФОИ в статусе "Черновик"» .

#### 1.5 Создание функции валидации при переводе в статус «В работа»

При выполнении операции перевода ФОИ из статуса «Черновик» в статус «В работа» система должна проверить:

- Поле «Уточняющая часть наименования» ≠ пустое
- Поле «Краткое описание» ≠ пустое

Условие успешного выполнения: оба поля заполнены. Результат: статус меняется на «В работа», все поля блокируются для редактирования in-line.

Условие ошибки: хотя бы одно поле пустое. Валидационное сообщение: «Для перевода в статус "В работа" необходимо заполнить: Уточняющую часть и Краткое описание» .

#### 1.6 Создание функции сохранения изменений in-line

При редактировании разрешённых полей:

- Изменения сохраняются при нажатии кнопки "Сохранить"
