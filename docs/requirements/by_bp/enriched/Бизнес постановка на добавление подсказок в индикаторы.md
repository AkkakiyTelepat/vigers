## Слой А. Структурированная карточка

### A.1 Термины и сокращения этой постановки

| Термин, сокращение | Определение |
|---|---|
| ДИТ | Департамент информационных технологий города Москвы |

### A.2 Подсистемы

ДИТ.Интеллект Калькулятор 2.0

### A.3 Компоненты (объекты доработки)

Работы, необходимые для реализации функционального требования, затрагивают:

- Редактор [Расчет - индикаторы] (CalcIndicatorsEditor)
- Редактор [Итерация - индикаторы] (IterationsCalcIndicatorsEditor)

### A.4 Цель и концепция решения

4.1. Цели и обоснование необходимости развития

Целью выполнения работ, необходимых для реализации функционального требования, является добавление подсказок в индикаторы на экранных формах сервиса ДИТ.Интеллект Калькулятор 2.0.

4.2. Описание проблем и решения

Реализация работ, описанных в данной постановке, позволяет решить проблему отсутствия подсказок, информирующих о том, как определяются значения индикаторов.

### A.7.1 Раздел 5 «Требования к результату» полностью (дословно)

Сценарий просмотра подсказок в экранных формах

| Действующие лица | Аналитик (Подрядчик) Руководитель проекта (ДИТ) Аналитик (ДИТ) |
|---|---|
| Предварительные условия | Пользователь авторизован в системе |
| Результат | В индикаторах на экранных формах [Расчет - индикаторы] и [Итерация - индикаторы] отображаются подсказки (значки вопроса), при наведении курсора на которые во всплывающем окне отображаются пояснения об определении значения индикаторов в сервисе ДИТ.Интеллект Калькулятор 2.0 |
| Основной сценарий | Открытие расчета по заявке и итерации Пользователь открывает расчет по заявке Система отображает подсказку (значок вопроса) возле каждого из индикаторов Пользователь открывает итерацию расчета по заявке Система отображает подсказку (значок вопроса) возле каждого из индикаторов Просмотр подсказок в индикаторах Пользователь наводит курсор на подсказку (значок вопроса) возле индикатора Система отображает пояснение об определении значения индикатора в сервисе ДИТ.Интеллект Калькулятор 2.0 |

В настройке обработчика события для редактора [Расчет - индикаторы] (CalcIndicatorsEditor) или редактора [Итерация - индикаторы] (IterationsCalcIndicatorsEditor) найти блок формирования компонента "Индикатор с типом" (см. рис. 3).
