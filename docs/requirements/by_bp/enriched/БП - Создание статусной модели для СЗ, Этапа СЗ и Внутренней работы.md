## Слой А. Структурированная карточка

### A.1 Термины и сокращения этой постановки

| Термин / Сокращение | Определение |
|---|---|
| СЗ | Служебное задание - документ, инициирующий выполнение определенного объема работ в рамках проекта или операционной деятельности |
| Этап СЗ | Логически обособленная часть Служебного задания, представляющая собой совокупность взаимосвязанных Внутренних работ, направленных на достижение промежуточного результата |
| Внутренняя работа | Минимальная единица планирования и учета в рамках Этапа СЗ, характеризующаяся конкретным перечнем задач и требуемых документов |
| Статусная модель | Совокупность статусов, правил и условий их смены для сущности (СЗ, Этап СЗ, Внутренняя работа), определяющая жизненный цикл этой сущности в систем |
| Статус | Атрибут, определяющий текущее состояние жизненного цикла сущности (например, "В работе", "Завершено", "Архив", "Корзина") |
| Перевод статуса | Действие (автоматическое или ручное) по изменению текущего статуса сущности на другой допустимый статус в соответствии с правилами статусной модели |
| Архив | Статус и/или логический раздел реестра, предназначенный для хранения завершенных и более неактуальных объектов (СЗ, Этапов СЗ, Внутренних работ), исключенных из основного рабочего процесса |
| Корзина | Статус и/или логический раздел реестра, предназначенный для временного хранения объектов, которые были удалены или помечены на удаление пользователем с возможностью последующего восстановления |
| НСИ | Нормативно-справочная информация - подсистема или раздел системы, содержащий справочные данные и классификаторы |
| ДИТ | Департамент информационных технологий (или соответствующее подразделение, отвечающее за ИТ-инфраструктуру и разработку) |
| Руководитель проекта (ДИТ) | Роль пользователя, обладающая расширенными правами на управление статусами СЗ, Этапов СЗ и Внутренних работ |
| Администратор | Роль пользователя с полными правами на управление объектами системы, включая перевод статусов и администрирование |
| Администратор НСИ | Роль пользователя, специализированная на управлении нормативно-справочной информацией, включая возможность управления статусами |
| Реестр | Список сущностей определенного типа (например, реестр Служебных заданий), отображаемый в системе с возможностью фильтрации, сортировки и просмотра детале |

### A.4 Цель и концепция решения

4.1. Цели и обоснование необходимости развития

В данный момент в ДИТ.Калькулятор нет возможности отслеживать статусы по Служебным заданиям(СЗ), Этапа СЗ и Внутренним работам

Для решения данной проблемы необходимо доработать ДИТ.Калькулятор в части создания статусных моделей для Служебного задания, Этапа СЗ и Внутренней работы
