# 4. Цель и концепция решения

## 4.1. Цели и обоснование необходимости развития

Цель работ – снижение нагрузки на операторов службы технической поддержки и сокращение времени освоения сервиса "Калькулятор" пользователями через создание встроенной системы справочных материалов.

Для решения задачи создается раздел "База знаний" с ролевым доступом, где каждый пользователь видит только актуальные для его роли материалы. Внутри раздела реализуются три способа работы с информацией: переход по кнопке на соответствующую страницу в Confluence для онлайн-просмотра, скачивание Word-версии документа для офлайн-работы и просмотр содержимого непосредственно в интерфейсе Калькулятора без переключения на внешние ресурсы.

## 4.2. Описание проблем и решения

Проблемы:

- Неудобный интерфейс текущих инструкций – материалы в Confluence представлены в виде длинных текстов без интерактивных элементов, что затрудняет поиск нужной информации
- Отсутствие централизованного инструмента обучения – пользователи вынуждены переключаться между различными внешними ресурсами, что замедляет процесс работы
- Сложность освоения нового функционала – пользователи тратят время на поиск нужных разделов и не получают быстрого доступа к справочной информации
- Рост нагрузки на поддержку – из-за неудобного формата инструкций увеличивается количество повторяющихся запросов

Решение:

Решение переносит всю справочную инфраструктуру внутрь Калькулятора: база знаний консолидирует документацию с гибким доступом и древовидной навигацией, обеспечивая два формата работы с материалами (встроенный просмотр, переход в Confluence), а ролевая фильтрация отображает только релевантную информацию для каждого типа пользователей.

# 6. Автоматизация бизнес-процессов

Бизнес-процесс "Получение технической поддержки через Базу Знаний"

[BPMN diagram BZ powered by viadee ]

Процесс инициируется, когда пользователь авторизуется в сервисе ДИТ.Калькулятор и у него возникает вопрос или необходимость получить справочную информацию.

Пользователь открывает раздел "База Знаний" в левом навигационном меню. Система отображает древовидную структуру основных разделов справочных материалов согласно функции 1.1. Пользователь раскрывает интересующий основной раздел, и система показывает список подразделов, отфильтрованных по его роли в соответствии с функцией 1.4.

При выборе подраздела пользователю доступны два варианта работы с материалом:

1. Просмотр встроенной версии – пользователь кликает по названию подраздела, и система открывает встроенную в интерфейс Калькулятора версию информации с содержимым раздела
2. Переход в Confluence – пользователь кликает по текстовой гиперссылке подраздела, и система открывает новую вкладку браузера с соответствующей страницей в Confluence согласно функции 1.3

Если в базе знаний пользователь нашел нужную информацию, вопрос решен и процесс завершается. Если ответ не найден, пользователь может попробовать другой раздел базы знаний или обратиться в службу технической поддержки.

# 7. Пользовательский сценарий (путь)

## Пользовательский сценарий прохождения базовой интерактивной онбординг-презентации при первом входе в систему

1. Пользователь впервые авторизуется в сервисе Калькулятор
2. Система определяет роль пользователя и автоматически запускает базовую интерактивную онбординг-презентацию, соответствующую его роли: если роль "Администратор", то автозапуск не выполняется и пользователь переходит к работе в системе, если другая роль, переходим к п.3
3. Отображается первый шаг обучения с подсказкой по базовому функционалу, актуальному для роли пользователя
4. Пользователь нажимает кнопку "Далее"
5. Отображается следующий шаг обучения: если пользователь дошел до последнего шага, то переходим к п.6, если остались шаги, то возврат к п.4
6. Пользователь нажимает кнопку "Готово"
7. Интерактивная презентация завершается, пользователь переходит к работе в системе

## Пользовательский сценарий работы с обучающими презентациями по бизнес-процессам из раздела "Интерактивное обучение"

1. Пользователь авторизуется в сервисе Калькулятор
2. Пользователь открывает раздел "База знаний" в левом меню
3. Пользователь раскрывает основной раздел "Обучение и Руководства"
4. Пользователь выбирает подраздел "Интерактивное обучение"
5. Система отображает карусель предпросмотра обучающих сценариев с центральной карточкой и частично видимыми боковыми
6. Пользователь просматривает сценарии, используя стрелки навигации для перелистывания карусели: если пользователь хочет изменить режим отображения, переходим к п.7, если выбирает сценарий из карусели, переходим к п.11
7. Пользователь выбирает режим отображения: если нажимает переключатель "По статусам", переходим к п.8, если нажимает переключатель "По тематикам", переходим к п.9
8. Система отображает галерею сценариев, сгруппированных по статусам прохождения: "Не пройденные", "Частично пройденные", "Пройденные сценарии", переходим к п.10
9. Система отображает галерею сценариев, сгруппированных по тематическим блокам: "Обучение основному функционалу", "Обучение изучению функционалу исходя из функционалу" (с ролевой фильтрацией), "Новый функционал"
10. Пользователь просматривает сценарии в выбранном режиме галереи: если роль "Администратор", то видит все сценарии всех ролей во всех блоках, если другая роль, то в блоке "Обучение изучению функционалу исходя из функционалу" видит только сценарии своей роли
11. Пользователь выбирает интересующий обучающий сценарий из карусели или галереи
12. Система проверяет статус сценария: если сценарий не начат (белая карточка, 0%), переходим к п.13, если сценарий в процессе (желтая карточка с процентом), переходим к п.14, если сценарий завершен (зеленая карточка), переходим к п.15
13. Пользователь нажимает кнопку "Начать" на белой карточке, переходим к п.16
14. Пользователь нажимает кнопку "Продолжить" на желтой карточке, переходим к п.16
15. Пользователь нажимает иконку обновления на зеленой карточке для повторного прохождения
16. Система запускает выбранную интерактивную презентацию по конкретному бизнес-процессу
17. Пользователь проходит обучение, нажимая кнопку "Далее" для перехода между шагами
18. Система обновляет процент прохождения сценария и изменяет статус карточки в реальном времени: при частичном прохождении карточка становится желтой с индикатором процента, при завершении — зеленой с кнопкой "Завершено"
19. По завершении пользователь нажимает кнопку "Готово" и возвращается к разделу "Интерактивное обучение" с обновленным статусом сценария

## Пользовательский сценарий работы с разделом "База знаний" для пользователя с любой ролью

1. Пользователь авторизуется в сервисе Калькулятор под любой ролью
2. Пользователь открывает раздел "База знаний" в левом меню
3. Система отображает древовидную структуру основных разделов справочных материалов
4. Пользователь раскрывает интересующий основной раздел
5. Система отображает список подразделов, актуальных для роли пользователя
6. Пользователь выбирает интересующий подраздел: если необходимо просмотреть встроенную версию информации, то переходим к п.7, если необходимо перейти в Confluence, то переходим к п.9
7. Пользователь кликает по названию подраздела
8. Открывается встроенная в интерфейс Калькулятора версия информации с содержимым раздела
9. Пользователь кликает по текстовой гиперссылке подраздела
10. Открывается новая вкладка браузера с соответствующей страницей в Confluence

## Алгоритм фильтрации подразделов по роли пользователя

Назначение: Обеспечение отображения только релевантных подразделов базы знаний в зависимости от роли текущего пользователя.

Входные данные:

- Роль текущего пользователя (Аналитик ДИТ / Аналитик подрядчика / РП ДИТ / Администратор)
- Список всех подразделов основного раздела с привязкой к ролям

Логика работы:

1. Система определяет роль текущего авторизованного пользователя
2. Пользователь раскрывает основной раздел в древовидной структуре
3. Система проверяет роль пользователя: Если роль = "Администратор": отобразить все подразделы без фильтрации Если роль ≠ "Администратор": отобразить только подразделы, для которых в метаданных указана роль текущего пользователя
4. Система формирует список видимых подразделов
5. Отображение подразделов в панели навигации

Выходные данные:

- Отфильтрованный список подразделов, доступных для просмотра пользователем с текущей ролью

# 8. Функции системы

8.1. Создание функции отображения информации пользователю в таком же виде, как она хранится во внутренних файлах ИС для раздела "База знаний" с древовидной структурой основных разделов

Функция должна обеспечивать отображение древовидной структуры основных разделов справочных материалов в левой панели навигации раздела "База знаний". Древовидная структура включает основные разделы (рис. UI 1) с возможностью их раскрытия для просмотра вложенных подразделов.

8.2. Создание функции отображения информации с обработкой (изменением) исходных данных для раскрытия/сворачивания основных разделов

Функция должна обеспечивать интерактивное раскрытие и сворачивание основных разделов древовидной структуры по клику пользователя на стрелку или название раздела. При раскрытии раздела система отображает список вложенных подразделов. При сворачивании – скрывает их. Состояние разделов (раскрыт/свернут) сохраняется в рамках пользовательского сеанса.

8.3. Создание функции вызова внешнего сервиса без сохранения данных для перехода на страницу в Confluence из раздела "База знаний" по клику на гиперссылку

Функция должна обеспечивать переход на соответствующую страницу в Confluence при клике пользователя по текстовой гиперссылке подраздела. Система открывает новую вкладку браузера с целевой страницей Confluence без сохранения данных о переходе в базе данных Калькулятора.

8.4. Создание функции фильтрации подразделов по роли пользователя внутри основных разделов "База знаний"

Функция должна обеспечивать отображение только тех подразделов, которые актуальны для роли текущего пользователя. Для ролей "Аналитик ДИТ", "Аналитик подрядчика", "РП ДИТ" система фильтрует подразделы согласно настройкам доступа. Для роли "Администратор" система отображает все подразделы без фильтрации.
