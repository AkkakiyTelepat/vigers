## 7.1. Описание алгоритмов

1. Расчет Готовности отчетных документов (ОД) в этапе

Необходимо рассчитывать готовность отчетных документов в рамках Этапа СЗ.

Готовность ОД в Этапе СЗ = округлить до целого значения ((сумма по количеству ОД в этапе в статусе "Подписан" /сумма по количеству ОД в этапе, статус которых != "Отклонен") * 100%)

Если Плановая дата окончания Этапа < Текущей даты И Готовность ОД в Этапе СЗ != 100%, то система подсвечивает поле "Красным" цветом

Иначе система подсвечивает поле "Зеленым" цветом

2.  Расчет Дней до окончания работы/заявки

Необходимо рассчитывать количество оставшихся дней до окончания работы

Кол-во оставшихся дней = (Плановая дата окончания Этапа - Текущая дата)

Если значение отрицательное, то система подсвечивает поле "Красным" цветом

Если значение положительное ИЛИ равно 0, то система подсвечивает поле "Зеленым" цветом

3. Готовность отчетных документов в работе

Необходимо рассчитывать готовность отчетных документов в рамках Работы.

Готовность ОД в Работе= округлить до целого значения ((количество ОД в работе в статусе "Подписан" /количество ОД в работе, статус которых != "Отклонен") * 100%)

Если Плановая дата окончания Этапа < Текущей даты И Готовность ОД в Работе != 100%, то система подсвечивает поле "Красным" цветом

Иначе система подсвечивает поле "Зеленым" цветом

# 8. Функции системы

8.1.1 Развитие функции отображения информации пользователям через интерфейс системы на ЭФ "Редактор СЗ" путем добавления вкладки "Календарный план СЗ"

Необходимо создать вкладку "Календарный план СЗ" на ЭФ "СЗ"

Путь до ЭФ: Главная страница/Расчет по методике 3-Р/НСИ/Контракты и задлания/СЗ/вкладка "Календарный план СЗ"

Макет вкладки "Календарный план СЗ" на ЭФ "Редактор СЗ" представлен на рисунке 1

Цель доработки: Доработать карточку СЗ в части создания вкладки "Календарный план СЗ" для отображения сводной аналитики по бюджету и заполнению отчетных документов по СЗ в разрезе Этапов СЗ и Работ

Необходимо создать вкладку "Календарный план СЗ". На вкладке будет расположен реестр "Календарный план СЗ" состоящий из 3 уровней вложенности: 1. Этап СЗ, 2. Работа/Заявка, 3. Отчетные документы.

Реестр должен автоматически формироваться наполняясь информацией из сущностей Этап СЗ, Работа, Отчетный документ (Проект документа) в момент заведения карточки СЗ и обновляться данными в момент создания/редактирования данных в карточках Этапа СЗ, Работы, Отчетного документа.

В реестре необходимо настроить сортировку по следующему принципу:

1. Сортировка для реестра 1 уровня: Первая сортировка по "Статус этапа СЗ": Сначала статус В работе, потом статус Черновик, далее статус Завершено (все что завершеноулетает вниз реестра) Вторая сортировка по "Номер Этапа": От меньшего к большему
2. Сортировка для реестра 2 уровня: Первая сортировка по "Статус работы": Сначала статус В работе, потом статус Черновик, далее статус Завершено Вторая сортировка по "Номер Работы": От меньшего к большему
3. Сортировка для реестра 3 уровня: Первая сортировка по "Статус документа": Сначала статус Все статусы кроме Черновик и Подписано, потом статус Черновик, далее статус Оплачено (все что оплачено улетает вниз реестра)

Статус Архив не учтен в сортировке, т.к. переход в этот статус осуществляется только после перевода всех документов в предфинальный статус (Завершено, Подписано). При переводе в статус Архив сортировка осуществляется только по Номеру Этапа и Номеру работы

| 9 | Расчет готовности отчетных документов в этапе | 1. Пользователь переводит отчетные документы, относящиеся к этапу, в статус «Подписан» 2. Смотрит поле «Готовность отчетных документов в этапе» (прогресс-бар) | Значение рассчитывается по формуле: округление до целого ( (количество ОД в этапе со статусом «Подписан» / общее количество ОД в этапе (статус не «Отклонен») ) * 100% ). При просрочке плановой даты окончания этапа и готовности < 100% поле подсвечивается красным, иначе зеленым |
| 10 | Расчет количества дней до окончания работы/заявки | 1. Пользователь смотрит поле «Дней до окончания работы» | Значение рассчитывается как (плановая дата окончания этапа, содержащего работу- текущая дата). Если значение отрицательное, поле подсвечивается красным; если положительное или 0 - зеленым |
| 11 | Сортировка записей в реестре «Этапы СЗ» | 1. Пользователь открывает вкладку с реестром этапов 2. Проверяет порядок строк | Сначала отображаются этапы со статусом «В работе», затем «Черновик», затем «Подписано». Внутри каждой группы сортировка по номеру этапа (по возрастанию). Статус «Архив» отображается в конце (после «Подписано») |
| 12 | Сортировка записей в реестре «Работы/Заявки» | 1. Пользователь разворачивает этап и смотрит список работ 2. Проверяет порядок строк | Сначала отображаются работы со статусом «В работе», затем «Черновик», затем «Оплачено». Внутри группы сортировка по номеру работы/заявки (по возрастанию) |
| 13 | Сортировка записей в реестре «Отчетные документы» | 1. Пользователь разворачивает работу и смотрит список отчетных документов 2. Проверяет порядок строк | Сначала отображаются статусы «Черновик» и «Подписан» (в любом порядке), затем «Черновик» (если есть). Статус «Архив» переводится после подписания и отображается в соответствии с сортировкой по номеру, но не влияет на сортировку по статусу |
| 14 | Обновление содержимого реестров (кнопка «Обновить») | 1. Пользователь нажимает кнопку «Обновить» на вкладке «Календарный план СЗ» | Происходит перезагрузка данных реестров (этапы, работы, отчетные документы) из базы данных. Отображаются актуальные изменения, внесенные другими пользователями или в результате интеграции |
| 15 | Пагинация и настройка количества записей на странице | 1. Пользователь открывает любой реестр на вкладке 2. Выбирает количество записей на странице (10, 25, 50, 100, 500) из выпадающего списка 3. Переключает страницы с помощью элементов навигации | Реестр отображает выбранное количество записей на странице. Навигация работает корректно, отображается общее количество записей и номер текущей страницы. Для первой страницы кнопка «Назад» неактивна, для последней - кнопка «Вперед» неактивна |
| 16 | Права доступа к вкладке «Календарный план СЗ» | 1. Пользователь с ролью «Администратор» открывает ЭФ «Редактор СЗ» 2. Аналогично для ролей «Администратор НСИ» и «Руководитель проекта (ДИТ)» | Вкладка «Календарный план СЗ» доступна для просмотра и работы. Пользователи с другими ролями (не указанными в требованиях) вкладку не видят или видят, но не могут взаимодействовать (в соответствии с политикой безопасности) |
| 17 | Открытие карточек этапа / работ / отчетного документа двойным кликом по строке реестра | 1. Пользователь дважды щелкает по строке в реестре «Этапы СЗ» 2. Аналогично для строки в реестре «Работы» и «Отчетные документы» | Открывается карточка соответствующей сущности (Этап СЗ, Работа, Отчетный документ) в режиме просмотра |
