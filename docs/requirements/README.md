# Документация требований к системе «ДИТ.Калькулятор»

Комплект документов требований, составленный по всем 68 бизнес-постановкам (БП) репозитория в подходе Карла Вигерса (K. Wiegers, «Разработка и управление требованиями»). Только факты из источников: проблематика, цели, стейкхолдеры, функциональные и нефункциональные требования, бизнес-правила, пользовательские сценарии, противоречия, допущения, открытые вопросы, глоссарий и трассируемость.

## Состав комплекта

| Файл | Содержание |

## Источники

- Корень репозитория: 68 файлов бизнес-постановок в формате `.doc`.
- `.extract/txt/`: текстовые извлечения тех же постановок (использовались для анализа).
- `promt`: исходное задание на формирование документации.

Каждый тезис в документах снабжён ссылкой на конкретный файл-источник; там, где источники молчат или противоречат друг другу, это зафиксировано явно (файл `07`), без домыслов.

## Полный реестр требований по источникам (без сокращений)

- [`by_bp/INDEX.md`](./by_bp/INDEX.md) — индекс 68 бизнес-постановок с объёмом и покрытием разделов шаблона.
- `by_bp/*.md` — **полный исходный текст каждой БП** (68 файлов, ~1,86 млн символов): все пользовательские сценарии, функции системы, поля ЭФ, алгоритмы, бизнес-правила, исключения, требования к данным, критерии приёмки — без консолидации и пересказа.

Документы 01–09 — аналитическая надстройка (сводные модели, статусные машины, противоречия C-1…C-10, матрицы трассировки); `by_bp/` — исчерпывающий первичный слой требований.
