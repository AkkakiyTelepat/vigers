# 4. Цель и концепция решения

4.1. Цели и обоснование необходимости развития

Цель - повысить удобство использования сервиса. Исключить лишние шаги пользователя необходимые для перехода к итерациям расчета.

4.2. Описание проблем и решения

На текущий момент пользователю приходится совершать 3 действия для перехода к экранной форме "Итерации", количество действий можно сократить до двух благодаря модернизации экранной формы заявки.

# 8. Функции системы

8.1. Развитие экранной формы "Заявка" в части добавления вкладки "Ресурсное планирование" и добавления итераций в выпадающее меню

На экранной форме "Работа" необходимо добавить новую вкладку " Ресурсное планирование " (рисунок 3 элемент 1). Вкладка должна быть доступна только для роли РП ДИТ.

На экранной форме "Работа" необходимо переработать логику отображения расчетов, если раньше при клике на выбранный расчет/БП, пользователь попадал на ЭФ "Карточка РСЗ", то теперь при клике на выбранный расчет, пользователю должен раскрываться список итераций этого расчета (рисунок 3 элемент 2), список итераций должен быть скрываемым при нажатии на элемент скрытия (рисунок 3 элемент 3). При нажатии пользователем на выбранную итерацию, должна открываться вкладка этой итерации (рисунок 6).

На экранной форме "Работа" необходимо добавить кнопки "Протокол обработки заявки" и "Расчет стоимости заявки" (рисунок 3 элемент 4), которые ранее располагались на ЭФ "Карточка РСЗ", логика работы кнопок не меняется. Кнопки должны быть активны только если РСЗ находится в статусе "Согласовано".

8.2 Развитие экранной формы "Итерация"

Необходимо удалить с ЭФ индикаторы: "Расчетные трудозатраты" , "Предельная трудоемкость". (рисунок 6) для всех ролей.

8.3 Удаление ЭФ "Карточка РСЗ"

Необходимо удалить из системы ЭФ "Карточка РСЗ" (рисунок 7), т.к. её функциональность перераспределена на другие экранные формы (описано выше).

8.4 Создание вкладки "Ресурсное планирование"

На экранной форме "Работа" необходимо добавить новую вкладку "Ресурсное планирование" , нажав на которую должна открываться ЭФ согласно рисунку 4 (для заявок), рисунку 4.1 (для расчетов без заявок).

ЭФ должна состоять из блоков:

1.Стоимость РСЗ

Функциональный блок содержит индикаторы: " Всего ", "Согласованная сумма", "Несогласованная сумма", алгоритмы расчета не изменяются.

В случае отображения вкладки "Ресурсное планирование" для работ без заявок индикаторы: "Согласованная сумма", "Несогласованная сумма" не должны отображаться.

2.Трудоемкость работы

Блок "Трудоемкость заявки"  должен содержать индикаторы "Расчетные трудозатраты" и "Предельная трудоемкость" , алгоритмы расчета не изменяются.

В блок "Трудоемкость заявки" должен быть перенесен блок "Размер команды" с удаляемой ЭФ "Карточка РСЗ" (пункт 8.3).

Справочно: требования к переносимому блоку описаны в постановке - БП - Изменение блока "Размер команды"

8.5 Развитие отображения экранных форм раздела "Работы" в части их отображения на весь экран пользователя по умолчанию

Для всех экранных форм раздела "Работы" необходимо изменить отображение по умолчанию, если сейчас ЭФ отображаются на половину экрана (рисунок 1), то теперь они должны отображаться на весь экран (рисунок 2).
