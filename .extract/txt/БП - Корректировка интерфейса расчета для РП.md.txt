Пользовательский сценарий работы с вкладкой "Размер команды" для пользователя с ролью "РП ДИТ"

1. Пользователь авторизуется в сервисе Калькулятор
2. Переходит во вкладку "Расчеты по методике 3-Р" - Расчеты
3. Выбирает необходимый расчет
4. Переходит во вкладку "РСЗ"

# 8. Функции системы

8.1 Развитие модального окна заполнения вкладки "Периоды работы по заявке" переименования в "Размер команды" и изменения состава полей и подсказок

Необходимо переименовать следующие элементы:

| Наименование | Было | Станет | Макет |
|---|---|---|---|
| Модальное окно "Периоды работы по заявке" | Периоды работы по заявке | Размер команды | рис.1.1 |
| Поле "Стоимость заявки, рублей" | Стоимость заявки, рублей | Стоимость по ФОТ, рублей | рис. 1.2 |
| Текст подсказки для поля "Стоимость заявки, рублей" | "Стоимость заявки по данному периоду" | "Расходы подрядчика на ФОТ при выполнении работ" | рис. 2.2 |
| Текст подсказки для поля "Дата начала" | "Дата начала работ по данной заявке. Руководитель проекта вносит данные из Jira" | "Дата начала выполнения работ подрядчиков" | рис. 3.2 |
| Текст подсказки для поля "Дата окончания" | "Дата окончания работ по данной заявке. Руководитель проекта вносит данные из Jira" | "Дата окончания выполнения работ подрядчиков" | рис. 4.2 |
| Текст подсказки для поля "Количество сотрудников" | "Примерное количество сотрудников, которые будут работать над реализацией данной заявки" | "Примерное количество сотрудников подрядчиков, привлекаемых для выполнения работ" | рис. 5.2 |

8.2 Развитие ЭФ РСЗ в части переименования блока "Периоды работы по заявке" в "Размер команды"

Необходимо переименовать таблицу "Периоды работы по заявке" (рис. 6.1) в "Размер команды" на экранной форме расчета, с крыть столбцы таблицы "Дата начала" и "Дата окончания", переименовать столбец "Стоимость заявки, рублей" в "Стоимость по ФОТ, рублей". Макет представлен на рис. 6.2.

8.3 Развитие цветовой индикации индикаторов и подсказок на ЭФ "РСЗ"

Необходимо изменить текст подсказок для индикатора "Расчетные трудозатраты" (рис. 6.4):

" Расчетные трудозатраты занижены " заменить на " Расчетная ставка чел/часа ниже рыночной "

" Расчетные трудозатраты завышены " заменить на " Расчетная ставка чел/часа выше рыночной "

Вариант подсказки " Расчетные трудозатраты в пределах нормы " исключить, т.е. если показатель в норме, текстом ничего не выводить пользователю.

Размер шрифта необходимо уменьшить - сделать таким же как следующая подсказка про сравнение расчетных трудозатрат с предельной трудоемкостью (фраза: "Расчетные трудозатраты завышены относительно предельной трудоемкости" на рис. 6.4).

Формулы для вывода подсказок (остаются без изменений):

- Расчетная ставка чел/часа ниже рыночной = (стоимость РСЗ (индикатор ВСЕГО) / Периоды работы по заявке (количество рабочих дней * количество сотрудников * 8)) < 2000

- Расчетная ставка чел/часа выше рыночной = (стоимость РСЗ (индикатор ВСЕГО) / Периоды работы по заявке(количество рабочих дней * количество сотрудников * 8)) > 5200

- Расчетные трудозатраты завышены относительно предельной трудоемкости = (Периоды работы по заявке(Стоимость заявки, рублей) / Ставка по ГК ) < Расчетные трудозатраты по заявке

Необходимо изменить цветовую индикацию индикатора "Расчетные трудозатраты" (рис. 6.5):

Индикатор красный, в случае вывода хотя бы одной из подсказок:

- Расчетная ставка чел/часа ниже рыночной

- Расчетная ставка чел/часа выше рыночной

- Расчетные трудозатраты завышены относительно предельной трудоемкости

Логика вывода подсказок остается без изменений, изменился только текст (описано выше).

В остальных случаях цвет индикатора "Расчетные трудозатраты" белый. В том числе цвет белый, если РП еще не внес сведения в таблицу "Размер команды" (бывшая таблица "Периоды работы по заявке")
