# 4. Цель и концепция решения

4.1. Цели и обоснование необходимости развития

1. Цель - внедрение статусной модели для функций с фиксированной стоимостью

Внедрение статусной модели для функций с фиксированной стоимостью в смете с целью регламентации процесса согласования описаний функций и бизнес-постановок. Статусная модель позволит организовать поэтапную проверку аналитиком (корректность и достаточность описаний, соответствие бизнес-постановок согласованным редакциям), разграничить состояния отдельных функций ("В работе", "Согласовано", "Не согласовано"), обеспечивая контроль качества данных до момента формирования ЧТЗ

2. Цель - отображение статуса функций с фиксированной стоимостью в карточке ГК

Обеспечение визуального контроля статуса исполнения работ с фиксированной стоимостью в карточке ГК путем автоматического отображения статуса соответствующей ФОИ из сметы типа «ФОИ из НМЦК». Реализация позволит ответственным лицам оперативно определять этап выполнения фиксированных работ на основе прогресса согласования сметы, понимая, какие работы уже утверждены, а какие находятся в процессе доработки/не выполнены

3. Переименование статусов ФОИ

Цель изменения статуса для функций обработки информации (ФОИ) - обеспечить единообразие и логическую корректность в рамках единой статусной модели Системы. Статус отражает не признак функции, а ее текущее состояние. Форма среднего рода "Согласовано" и "Не согласовано" грамматически правильнее выражает это абстрактное состояние для любых сущностей, независимо от их грамматического рода

4. Изменение положения столбцов на подвкладке "НМЦК по Заявке"

Повысить эффективность и логичность процесса анализа функций обработки информации (ФОИ) за счет оптимизации последовательности восприятия данных. Текущая последовательность "Наименование, Тип, Описание" вынуждает пользователя сначала формально классифицировать функцию по типу, не имея при этом полного понимания ее сути. Это может привести к ошибочным ассоциациям и снижает скорость анализа

# 7. Пользовательский сценарий (путь)

1. Сценарий работы с ФОИ из НМЦК Аналитиком Подрячика

Предусловие: Пользователь авторизован в системе под ролью Аналитик (Подрядчика), и находится на главной странице ДИТ.Калькулятор

1. Пользователь переходит к "Расчет по Методике 3-Р/Работы/Работа/ФОИ из НМЦК"

2. Пользователь кликает запись в реестре (выбирает смету фиксированной стоимость)

3. Пользователь нажимает на кнопку "Копировать из НМЦК"

4. Пользователь выбирает ФОИ из реестра и нажимает на кнопку "Редактировать"

5. Пользователь редактирует поле "Краткое описание" и нажимает на кнопку "Сохранить"

6. Пользователь переводит статус ФОИ в "На согласование" ( Если пользователю поступила ФОИ с комментариями, то переходим к шагу 7, иначе Конец сценария )

7. Пользователь выбирает в реестре ФОИ в статусе "Не согласовано" и нажимает на кнопку "Редактировать"

7.1 Пользователь редактирует поле "Краткое описание" согласно комментарию в поле "Комментарий" и нажимает на кнопку "Сохранить" (переходим к шагу 6)

2. Сценарий работы с ФОИ из НМЦК Аналитиком (ДИТ)

Предусловие: Пользователь авторизован в системе под ролью Аналитик (Подрядчика), и находится на главной странице ДИТ.Калькулятор

1. Пользователь переходит к "Расчет по Методике 3-Р/Работы/Работа/ФОИ из НМЦК"

2. Пользователь кликает запись в реестре (выбирает смету фиксированной стоимость) ( Если пользователь согласует ФОИ, то переходим к шагу 4. Если пользователь не согласует ФОИ, то переходим к шагу 5)

3. Пользователь выбирает ФОИ в реестре

4. Пользователь переводит статус проверенной ФОИ в "Не согласовано" ( Если пользователь хочет отменить изменение статуса, то переходим к шагу 4.2, иначе 4 .1)

4.1 Пользователь пишет комментарий с причиной не согласования и нажимает на кнопку "Применить" ( Если остались ФОИ в статусе "На согласование", то переходим к шагу 3, иначе переходим к шагу 5)

4.2 Пользователь кликает на кнопку "Отменить" (переходим к шагу 3)

5. Пользователь переводит статус проверенных ФОИ в "Согласовано" ( Если остались ФОИ в статусе "На согласование", то переходим к шагу 3, иначе Конец сценария )
