# 7. Пользовательский сценарий (путь)

1. Авторизоваться сервисе Калькулятор
2. Зайти в модуль "Расчет по методике 3-Р"
3. Зайти в раздел "Работы"
4. Зайти в существующую заявку / создать новую заявку
5. Обратить внимание на поле "Этап ГК"
6. Зайти в любой существующий /создать новый расчет заявки
7. В блоке "Периоды работ по заявке" нажать кнопку "Добавить"
8. Заполнить даты начала и окончания работ

# 8. Функции системы

8.1. Создание алгоритма ФЛК на экранная форме добавления периодов работы по заявке

Необходимо создать алгоритм ФЛК на полях экранной формы добавления периодов работы по заявке, для следующих полей:

"Дата начала" - диапазон выбираемых дат для заполнения должен начинаться с даты начала этапа ГК, указанного для этой заявки на ЭФ Заявки (рисунок 1, выделено красным)

- "Дата начала" >= дата начала этапа ГК

"Дата окончания" - диапазон выбираемых дат для заполнения должен заканчиваться последней датой этапа ГК, указанного для этой заявки на ЭФ Заявки (рисунок 1, выделено красным)

- "Дата окончания" <= дата окончания этапа ГК

При попытке пользователя указать значения выпадающие из допустимого диапазона, соответствующее поле должно подсвечиваться красным, а под строкой должен высвечиваться красный текст ошибки: "Не допустимо указывать даты не относящиеся к соответствующему этапу ГК" . Кнопка "сохранить" при этом не должна быть активна.
